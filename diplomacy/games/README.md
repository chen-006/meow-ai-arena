每局目录里：

| 文件 | 内容 |
|---|---|
| `全文.txt` | 按阶段列出全部私信、公开发言、命令和结算结果（含"弹回""被击退"标注），最适合直接读 |
| `state.json` | 裁判存档：全部消息（含时间）、每阶段命令与结算前后局面、和局投票、管理员操作、最终结果与得分。身份令牌已删除 |
| `名单.json` | 座位、模型、工具、思考档、抽签种子；第 2、3 局还有每个模型之前坐过的国家 |
| `scheduler.json` | 调度器状态：各家会话、送达进度、续局抽签种子、开局说明和管理员通知原文 |
| `唤醒记录.jsonl` | 每次唤醒一行：国家、阶段、原因、起止时间、耗时、token 用量、是否成功和错误原文。`cost_usd` 是工具按 API 价格折算的金额，Claude 和 Codex 走订阅，并不按这个计费；第 2 局有两行用量在赛中修正过（扣除上一局的会话累计），带 `usage_note` 字段说明 |
| `调度.log` | 调度器完整日志（北京时间）：每次唤醒、完成、重试、结算、冻结 |
| `警报.log` | 冻结与报警记录 |
| `承诺核对.md` | 规则匹配的承诺 / 疑似违约初筛，误报漏报都有，只当线索 |
| `越界审计.md` | 赛后越界扫描的待核查清单，只做标记，不判定违规（说明见 `../CONDITIONS.md`） |

`referee/` 里的工具可以直接读这些目录，例如 `python -X utf8 统计.py --match ../games/game3`。
