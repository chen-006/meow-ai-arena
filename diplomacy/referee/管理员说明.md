# 七国外交 · 管理员说明（v3）

> 开源注：这是第 1 局期间的说明，原样保留。之后加入的 `match.py rematch`（续局）和 `admin.py notice`（管理员通知）这里没有写，"选手看到什么""尚未决定"等段落也已过时。当前用法以 `../README.md` 为准；路径写法是 Windows 的。

模型直接当玩家：谈判、下令。本地裁判负责保密、结算和留档；调度器负责在有事时唤醒选手。

## 工作方式

- **每次唤醒 = 启动一次该选手 Agent 的命令行，续接它自己的会话。** 简报直接写在唤醒消息里，选手处理完就结束回复、进程退出。没有事件时没有任何选手进程在运行。
- 唤醒时机：进入它需要行动的新阶段、开局时立即唤醒；只有新消息时，等对话安静 10 秒（或最早一条已等 40 秒）再唤醒，把陆续到达的消息合并送达。选手正在处理时来的新消息也会合并到下一次。有消息未送达时不结算。
- 结算时机：所有需行动国家都交了军令，**且没有选手正在处理**时同时结算。收到新消息不会撤回已交的军令；读完不改就直接结束回复。
- 全员停下但有人没交军令：先唤醒该国催促一次；催促后仍没有任何动静，就冻结对局并写警报。
- 唤醒失败（报错、超时）：10 秒、30 秒、2 分钟后各自动重试一次，仍失败就冻结对局、写 `警报.log`。报错像额度用完（429、rate limit、quota 等）时不冻结，每 15 分钟重试一次，最多等 8 小时。重试时把没送达的内容重新送给它。

| 选手 | Agent | 唤醒命令 |
|---|---|---|
| Claude | Claude Code | `claude -p --resume`（不加载用户级设置、记忆、MCP；只允许本目录读写和运行 python） |
| GPT | Codex | `codex exec resume`（独立 CODEX_HOME，不读你的全局 AGENTS.md；workspace-write 沙箱） |
| 国模 | OpenCode | `opencode run --session`（私有服务；目录内 opencode.json 禁止联网和访问外部目录） |
| 测试 | 脚本 | `bots/hold_bot.py`（全部驻守）、`bots/lazy_bot.py`（什么都不做） |

## 操作

以下命令都在本目录运行（前缀 `.venv\Scripts\python.exe -X utf8`），不写 `--match` 时作用于 `管理员\对局\当前对局.txt` 记录的那一局。

```text
match.py new --roster 管理员\名单\xxx.json [--port 18791]   建新局
match.py run [--match 对局目录] [--stop-at S1905M]           运行 / 续跑（冻结状态会自动解冻）
admin.py status | pause | resume                              查看 / 冻结 / 恢复
admin.py stop                                                 冻结并在选手停下后让调度器退出
admin.py swap 国家 模型 [--effort 档位] [--label 名字]         停止后给某国换模型（同一种 Agent，沿用会话）
观战.py                                                       实时观战窗口（只读）
统计.py [--messages 8]                                        局势、中心变化、各家耗时与用量、最近消息
承诺核对.py                                                   "不进/不攻某地"类承诺 vs 实际命令，写入 承诺核对.md
回放.py                                                       生成单文件回放 对局目录\回放.html（含私信和模型名）
audit.py                                                      赛后越界审计
```

换模型：`admin.py stop` → `admin.py swap FRANCE gpt-6-astra --effort low` → `match.py run`。出现警报（冻结）时会弹 Windows 桌面通知。

名单格式（七国齐全）：

```json
{"players":[{"power":"FRANCE","harness":"codex","model":"gpt-6-sol","effort":"high","label":"GPT-6 Sol"},
            {"power":"ENGLAND","harness":"claude","model":"claude-opus-5-5","effort":"high","label":"Opus 5.5"},
            {"power":"GERMANY","harness":"opencode","model":"cline/cline-pass/kimi-k3","effort":"max","label":"Kimi K3"}],
 "wake_timeout_minutes":45}
```

OpenCode 的 `model` 写 `渠道/模型`，`effort` 会拼成 `#档位`；模型真实上下文小于 256k 时加 `"context": 真实长度`。

上下文：各家统一按 256k 窗口计算，满了用自家原生方式自动压缩（Codex 原生即 256k；Claude 设 `CLAUDE_CODE_AUTO_COMPACT_WINDOW`；OpenCode 在选手目录的 opencode.json 写模型 `limit`）。国模一律走 Cline 渠道（`cline/cline-pass/...`），不走 OpenRouter（按量计费，贵）；DeepSeek 用自己在 DeepSeek 开放平台购买的 key（在 OpenCode 里登记为 `deepseek` 渠道，名单写 `deepseek/模型名`；上场前实测确认模型名）。

## 文件位置

- 管理员：`管理员\对局\<局>\`：`state.json`（全部私信、秘密军令、凭据）、`scheduler.json`（会话与送达进度）、`唤醒日志\<国家>\`（每次唤醒的提示词和完整原始输出）、`唤醒记录.jsonl`（耗时、用量）、`调度.log`、`警报.log`、`codex_home\`。
- 选手：`C:\bench\外交\<局>\<国家>\`，与管理员目录不相邻。里面只有规则、说明、客户端、推演工具、地图资料和本国凭据。

## 选手看到什么

开局一次说明（代表哪国、目标、规则文件在哪、处理完就结束回复），之后每次唤醒只有简报：新消息原文、上阶段各国命令和结果、当前局面（换阶段时）、本阶段任务。合法命令不默认附带，下错会给出该部队的全部合法选项，也可以 `game.py legal` 查询。

## 计分与语言

- 单独胜利 100 分；和局（协议和局或 1920 年到期）按补给中心数平方分配 100 分（SoS）。结果写在 `state.json` 的 `result.scores`。
- 选手消息用中文。
