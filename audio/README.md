# 声音：音乐、音效、配音

节目里的声音分三块，这里放的是"用了什么、怎么调的"，方便照着做一份同样口味的视频。

| 文件 | 内容 |
|---|---|
| [music.md](music.md) | 每一集用了哪些背景音乐和音效：曲名、作者、出处、编号。**音频文件本身不在仓库里**（见下） |
| [tts.md](tts.md) | 配音怎么做的：旁白和各个角色用的合成服务、音色名、提示词原文、后期参数、读法处理、挑版本和查错的办法 |
| [tts/voices_breeze.json](tts/voices_breeze.json) | 全部角色的音色表（角色 → 音色编号、音色名、一句人设） |
| [tts/ep10_tones.md](tts/ep10_tones.md) | 第 10 集的逐句语气表原文：每一句送给合成的语气提示，以及个别句子改过的念法 |

## 为什么没有音频文件

- **背景音乐和音效**来自 [Mixkit](https://mixkit.co)。它的许可允许免费用在视频里（包括商用），不要求署名，但不允许把素材本身拿出来再分发，所以仓库里只放清单，按编号可以回原站下载。少量音效是节目自己用 ffmpeg 合成的，做法写在清单里。
- **配音成品**不放：声音是用第三方合成服务生成的，音色属于各家服务。这里公开的是音色名、提示词和参数，照着能配出同样的声音。

角色的生图提示词不在这里，在 [`art/prompts/`](../art/README.md)。
