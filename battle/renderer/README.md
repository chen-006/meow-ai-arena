# 渲染器

把模拟器的回放 `.wrp` 渲染成 1080p 30 帧的视频：体素小人、体素道具、每张图一个美术主题的小战场，斜俯视跟拍为主（贴着正在发生的事取景），大事件切按事件设计的近景，画面顶上叠一条比分牌式的信息栏。视频里的战斗画面都是它出的。

## 1. 要装什么

| 东西 | 版本 | 说明 |
|---|---|---|
| Blender | 5.2.4 LTS（测试过的版本；5.x 以下没测过） | 用 EEVEE 渲染，后台模式 `-b`，不需要装插件。放进 PATH，或用环境变量 `A12_BLENDER` 指到 `blender.exe`。Blender 自带的 Python 已经有 numpy，渲染脚本不需要另装东西。 |
| Python | 3.10 以上，装 `numpy`、`pillow` | 跑 `make_video.py`（读回放、算机位、画信息栏、调 ffmpeg）。`出片.cmd` 用 PATH 里的 `python`，别的解释器用环境变量 `A12_PYTHON` 指定。 |
| ffmpeg | 任意较新版本（测试过 7.1） | 合成 mp4。放进 PATH，或用 `A12_FFMPEG` 指定。 |
| 中文字体 | 默认 `C:\Windows\Fonts\NotoSansSC-VF.ttf`，没有就用微软雅黑 | 信息栏用。别的字体用 `A12_FONT` 指定（Linux、macOS 上要指定一个中文字体）。 |

关卡和对抗图默认读本仓库的 `battle/workspace/`（`levels/`、`maps/`），主帅的 AI 形象默认读仓库顶层的 [`characters/`](../../characters/README.md)，都不用设置。测试过的环境是 Windows 11；代码里没有只认 Windows 的东西，但别的系统没测过。

## 2. 出片（一条命令）

```text
出片.cmd <回放.wrp> [-o 输出.mp4] [--from 秒] [--to 秒] [--procs 3] [--samples 12]
         [--lord default|<名字>|<造型.json>] [--shots 机位表.json] [--no-close] [--pitch 度] [--names 甲,乙]
         [--no-hud] [--no-fx] [--no-shake] [--keep]
```

不用 `.cmd` 时：`python renderer/src/make_video.py <回放.wrp> [同样的选项]`。

例（在 `battle/` 下）：

```text
python replays/unpack.py L2_sol
renderer\出片.cmd replays\L2_sol.wrp -o L2_sol.mp4 --to 20 --names "GPT-6.2 Sol,守军"
renderer\出片.cmd replays\L4_gemini_carbon.wrp -o L4.mp4 --lord gemini_carbon
```

- 不带 `-o` 时输出到 `renderer/renders/<回放名>/<回放名>.mp4`（中间帧也在这里，不入库；`A12_WORK` 可改）。
- `--from/--to` 只出一段（秒）。片子包含回放最后一帧时，定格 3 秒出**结果牌**（过关 / 没过 / 某方获胜 + 怎么结束的 + 用时和剩余兵力）。怎么结束的按各关的过关条件写：第 1 关"全歼来敌"、第 2 关"全歼来敌，军旗未倒"、第 3 关"攻下炮台"、第 4 关"全歼峡谷守军"、第 5 关"镇山兽倒下"；没过的写"全军覆没""军旗被砍倒""主帅阵亡""时间到"（`hud.reason_text`、`hud.WIN_ELIM`）。
- `--procs` 并行的 Blender 进程数（默认 3）。在 32 线程 CPU + RTX 4060 笔记本显卡上，4 个进程合起来约 0.15～0.22 秒/帧，一分钟的回放约 5～7 分钟出完。内存紧张时减到 2～3。
- 断点续渲：中断后原样再跑同一条命令，已经渲好的帧会跳过。换了画面代码要重渲时，删掉 `renders/<回放名>/frames`。
- `--names` 信息栏上各方的名字（按队伍号，逗号分隔）。不给时闯关写"闯关方 / 守军"，对抗写回放里的座位名。
- `--no-close` 关掉自动近景，全程全景跟拍；`--pitch` 改默认俯角；`--no-fx` 不出特效、`--no-shake` 不要镜头震动（调试用）。

## 3. 出静帧

| 要什么 | 命令（在 `src/` 下） |
|---|---|
| 回放里某一帧 | `blender -b --factory-startup -P render_replay.py -- <回放.wrp> --out <目录> --still <帧号> [--cam x,z,y,宽度,俯角,方位] [--name 文件名.png] [--samples 24] [--no-shake]` |
| 兵种、主帅、道具、镇山兽定妆照 | `blender -b --factory-startup -P stills_units.py -- <目录> [close wide host poses lord boss] [--samples 32]` |

`--cam` 里空着的项沿用自动机位（例如 `--cam ,,,48` 只把宽度改成 48 米）。帧号 = 秒 × 30。找关键事件在第几帧，可以看 `replay.big_events()`；`python src/replay.py <回放.wrp>` 列出一份回放会触发哪些近景。

## 4. 镜头

`replay.director()` 每帧给一个机位（目标 x、z、高度 y、画面宽度、俯角、方位），三层叠起来：

1. **全景跟拍**（`replay.camera()`）。每帧先列出"值得看的点"并给权重：主帅、镇山兽 5；爆炸 4；滚动的雪球 4；在飞的石头 3；冲锋中的兵 2；刚出手、挨打、倒下的兵再加 1.5；在走的兵 1；站着的兵 0.3；军旗 1.5。然后按透视把这些点装进画面（上面给信息栏留出一条）：全装得下就全装，装不下就取**最热闹的一窗**，并优先留在上一帧看的地方，所以镜头不会停在两群人中间的空地上。窗里有三个以上在动手、在走的点时只按它们取景；有主帅、镇山兽时画面中心往它偏三成。最后在时间上平滑、往前看 0.35 秒。画面宽度限定在 `min_w`～`max_w`（默认 24～52 米，兵在 1080p 里约 60～130 像素高）。
2. **自动近景**（`replay.auto_shots()`，按事件分别设计）：

| 事件 | 怎么拍 |
|---|---|
| 桥断 | 事件前 1.8 秒推到 26 米宽、俯角 31 度，顺着峡谷看；断了以后目标点跟着往下落 3 米，看人跟着桥掉下去；3.4 秒后拉回 |
| 雪球撞穿路障 | 雪球松开后就跟着球走（25 米宽、俯角 29 度），撞穿后再跟 2.4 秒 |
| 镇山兽撞晕（每一次） | 从刨地开始跟着它，镜头转到冲撞方向的侧面（最多偏 38 度），25 米宽、俯角 28 度：冲过来、撞上、头顶转星星 |
| 石头落地 | 对着第一块砸中人的石头的落点（之后每隔 14 秒以上再拍一块，最多三次） |
| 骑兵撞枪阵 | 第一波架枪迎击：22 米宽、俯角 27 度、偏 18 度 |
| 军旗倒、木栅 / 门被砸开 | 原地近景 |
| 守军出击（`sortie`） | 出击前 0.5 秒起跟着这一队的中位位置走 2.6 秒，宽度装下整队（22～34 米）、俯角 34 度 |
| 山口集结的敌军出发（`rally_go`） | 出发前 1 秒切到集结点，跟着整群人走 3.5 秒（26～44 米宽） |
| 主帅阵亡（第 4 关没过） | 倒下前 2.2 秒推到主帅身上（19 米宽），一直留到结果牌 |

   **小字提示**（`replay.captions`，信息栏画）：守军出击、集结的敌军出发时，左上关卡牌下面从左边滑出一行小字，停 3 秒左右淡掉，例如"坡顶守军出击　16 人""山口敌军压过来　78 人 · 等够了时间"。

   **四方混战的开场**（`replay._melee_intro`）：第一次真正交手之前，依次给每一队一个正面近景（镜头在岛中间朝外看），每队 0.8～1.1 秒、硬切；再切到方位 45 度的高俯全景停 1.3 秒，1.2 秒内转回正南、交给自动跟拍。开打得早、时间不够时只留全景，不到 2 秒就不加。

   近景里主体放在画面中间偏下一点（上面是信息栏）。挨得近的两段近景会连起来，不来回推拉。大的撞击（爆炸、桥断、镇山兽撞上东西、路障碎、石头落地）带一下 0.6 秒内衰减的镜头震动。
3. **手动机位表**（`--shots 文件.json`）盖在最上面：

```json
{
  "auto":  {"pitch": 40, "min_w": 24, "max_w": 52, "yaw": 0, "auto_close": true, "close_scale": 1.0},
  "shots": [
    {"from": 6.0, "to": 10.5, "target": [0, 0], "width": 18, "pitch": 30},
    {"from": 20,  "to": 24,   "unit": 38, "width": 24, "ease": 1.0},
    {"from": 30,  "to": 36,   "target": [-10, 5, 2], "width": 60, "yaw": 20}
  ]
}
```

`from/to` 秒；`target` 是 [x, z] 或 [x, z, 高度]；`unit` 跟拍某个物体编号（回放 META 的 objects 里有）；`width` 画面宽度（米）；`pitch` 俯角；`yaw` 方位（0 = 从南往北看，甲方 / 闯关方在下面；正值 = 镜头绕到西南往东北看）；`ease` 进出过渡秒数（默认 0.8）。没写的项沿用自动机位。`auto` 段改自动机位的参数：`close_scale` 把所有自动近景的宽度乘一个数（小于 1 更近）。

**每张图的默认机位**写在 `themes/<图名>.render.json` 的 `"camera"` 段：`pitch`、`min_w`、`max_w`、`yaw`、`close_pitch_min`（自动近景的俯角下限）、`orbit`（true = 绕岛机位：镜头总在正在打的地方外侧朝岛中间看，涨潮沙洲开着，因为正中有礁石和灯塔）。一线天是 `pitch` 46、`yaw` -50、`close_pitch_min` 42：镜头在坡上顺着下坡斜着看，峡谷从右下往左上横贯画面。

## 5. 特效、动作、消失

- **特效**全部是粒子（`src/fxsys.py`）：一小团方块按公式飞出去、长大、缩没，不透明，个头小、散得快，不盖主体。爆炸 = 白闪 + 贴地冲击波 + 火团 + 一团团小烟 + 火星 + 碎块；兵器命中 = 小四角星 + 火星（被盾挡住只有火星）；骑兵、镇山兽冲锋脚后扬尘，镇山兽刨地往后刨土；雪球滚动贴地雪雾；石头飞行拖一串小灰团、落地尘土碎石；桥塌、木栅和门碎是碎木，立石碎是碎石 + 冲击波。飞行中的箭带一道发亮的拖尾。
- **受击**：掉血的那一帧整个人往暖白提亮，0.2 秒内退掉，身子往后仰一下（镇山兽只闪三成多）。同一个人 0.4 秒内只闪一次。调强弱改 `army.FLASH_MIX / FLASH_EMIT`、`render_replay.HIT_S`、`replay.HURT_GAP`。
- **动作**（`army.py`）：位置和整体朝向全照引擎的刚体，肢体动作有意夸张：走路身子前倾、一步一颠；出手是"后仰蓄力 → 整个人扑出去"；骑兵冲锋时马前后腿成对蹬；镇山兽有站、走、刨地、冲撞、撞晕（头顶三颗星）、甩头。
- **消失**：引擎里尸体 8 秒后消失、雪球停稳 3 秒后消失，回放里是直接没了；画面上尸体 1.2 秒沉入地面，雪球碎成一堆雪块化掉，石头和箭缩没。
- **第 1 关脚上带泥**：回放没有专门的字段，按 [回放格式.md](../engine/回放格式.md) 的推法（`replay._mud`）：带泥的单位腿的下半截换成泥色，马披、裙摆下沿溅几块泥点，在泥里走脚下溅泥水，出了泥塘还一路往下掉泥块。
- **涨潮沙洲**：水面每帧按回放时间上涨，湿沙带、浪花、浅水圈跟着岸线走；比分牌下面多一条"沙洲"：沙色是剩下的半径、蓝色是被淹掉的。
- 土丘（mound）和引擎一样画成直的圆台（引擎用凸包做碰撞）；第 4 关的两道路障木栅和引擎一样 9.8 米宽。

## 6. 换主帅造型

第 4 关的主帅默认是**通用将领**（`units.m_lord()`：金盔 + 高高的队伍色盔缨、背上两面令旗、队伍色肩甲和披风、竖拿的大刀），原创。

要换成某家 AI 的体素形象：`--lord <名字>` 或 `--lord <造型.json 的路径>`。给名字时依次在环境变量 `A12_LORD_DIR` 指的目录、仓库顶层的 [`characters/`](../../characters/README.md) 里找 `<名字>.json`（名字就是席位名：`sol`、`fable`、`gemini_carbon` 等）。找不到就打印一行提示、用通用将领。AI 形象按 1.7 倍放大（它们是大头小人），通用将领 1.3 倍。

## 7. 文件

```text
renderer/
  出片.cmd            一条命令出片（调 src/make_video.py）
  themes/<图名>.render.json   每张图的附加布景（只给渲染器用，引擎不认）：场外地形 surround、布景散布 decor（树、石、草、花、
                      冰棱、芦苇、平顶山、石笋、贝壳、海星、海草、滩涂草、浮木、矮礁石）、土路 paths、废墟 ruins、谷底深度 deep、
                      营地布景 camp、海里的礁柱 sea_stacks 和破船 wrecks、正中地标 landmark、镜头参数 camera。
                      地形、道具、守军、布阵区一律以引擎的正式文件（回放里带着原文）为准。
  src/
    make_video.py     出片主程序（普通 Python）：分段并行调 Blender → 信息栏 → ffmpeg
    render_replay.py  Blender 入口：一份回放 → 一段帧 / 一张静帧；每帧按回放摆单位、道具、特效、断桥、碎片、相机
    replay.py         读 .wrp（纯 numpy）；走路相位、出手时间、镇山兽状态、脚上带泥；全景跟拍、按事件设计的近景、
                      导演 director()、镜头震动、小字提示
    hud.py            信息栏（Pillow）：顶部比分牌、血条、涨潮图的"沙洲"条、结尾结果牌
    scene.py          把一张地图搭成场景（地形、水和潮位、泥塘、土路、布景、雪球挡木），加单位
    terrain.py        引擎地图格式 → 网格（box / ramp / cyl / mound / hull / forest）；读 render.json；高度查询
    builders.py       场景物件：树、石头、草丛、花、桥、房子、钟楼、礁石、废墟、平顶山、石笋……
    mats.py           地形材质：地面、崖壁、冰、铺石、砌墙、水、泥塘、土路、台地顶
    looks.py          八个主题的配色和光照（草甸、红岩峡谷、古垣、冰原峡谷、石阵荒原、春樱、老城、沙洲）
    units.py          9 个兵种 + 镇山兽 + 通用主帅 + 道具（雪球、火药桶、军旗、木栅、木栅门、立石）的体素模型；主帅造型的查找
    army.py           单位在 Blender 里的装配（部件网格共用、队伍色靠物体颜色）、描边、脚下色环、各种姿势
    fx.py             箭、石头和粒子用的小模型
    fxsys.py          粒子系统：把回放里的事件和状态变成粒子，每帧摆
    stage.py          渲染设置、太阳、相机
    scene_lib.py      材质节点小工具、天空、清场（节目通用的渲染管线）
    voxkit.py、geom.py 体素建模和网格拼装工具
    stills_units.py   定妆照（兵种、主帅、道具、镇山兽）
```

兵种、道具、镇山兽、通用主帅的模型都是 `units.py` 里的代码（"往格子里放方块"），没有单独的模型文件；运行时在 Blender 里生成。

## 8. 画面约定

- 坐标：Blender (X, Y, Z) = 引擎 (x, z, y)；四元数 (qx, qy, qz, qw) → Blender (qw, −qx, −qz, −qy)，再转 180 度对齐模型朝向（`army.Unit.place_q`）。
- 队伍色：0 蓝 #2F6BFF、1 红 #F0302C、2 绿 #18B45A、3 紫 #A64BF0（`army.TEAM_HEX`，信息栏同一套）。闯关里选手是 0（蓝），守军是 1（红）。
- 阵亡：压暗去饱和、脚下色环隐藏；倒地、被击飞时色环也隐藏。
- 信息栏在画面最上面一条；自动机位取景时给它留了位置（`replay.SAFE`）。下面不放东西，留给字幕。

## 和制作时的差别

- 本机路径换成了环境变量和 PATH：Blender、ffmpeg、Python 不再有默认的本机位置；中间帧默认放在 `renderer/renders/`；关卡和对抗图默认读 `battle/workspace/`（同时认 `levels/` 和引擎原来的 `关卡/` 目录名）；主帅形象默认读仓库的 `characters/`。场景主题目录从 `关卡/` 改名 `themes/`。
- 没有收录两个只服务于节目制作的脚本：`make_samples.py`（一条命令重出节目样片）和 `stills_scenes.py`（八张图的场景静帧），它们依赖主办方自己摆的演示回放，不在仓库里。
- `stills_units.py` 定妆照里的 AI 形象主帅从 `opus` 换成 `fable`（`characters/` 里没有 opus）。
- 注释里提到另一集名字和道具的几处（`looks.py`、`voxkit.py`）改成了泛称。

第三方依赖见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
