# 第 12 集分析稿与探索实验

本目录收录第 12 集《OA 争霸·下》（5v5 回旋镖团队赛）的赛事数据汇总、双队源码与策略解析、费用表、帕累托量化分析及三波赛后控制变量小实验，供读者理解两支队伍的设计思路与六回合博弈。

> **免责声明**：本目录分析稿由 AI（Gemini 4 Neon 负责双队源码与策略初稿解析，GPT-6.2 Sol 负责硬数据总账、回放统计、量化帕累托、三波对照实验及逐条事实核查）整理并核对，即便如此仍可能有误，**一切以选手源码（[`../bots/`](../bots/README.md)）和对局数据（[`../results/`](../results/README.md)）为准**。

## 口径说明

- 收录前已清理内部制作说明、本机绝对路径与内部运维记录，不收录任何选手原始会话日志或原始思考原文。
- 文中提及的源码行号默认对应 [`../bots/`](../bots/README.md) 中各选手最终的 `player.cpp`（Astra 与 GLM 区分开发冻结时的 `交卷.cpp` 与亲手改后的 `player.cpp`）。
- 占点模式（`piers`）的 A / B / C 均按**本队在左**的视角书写；当两队同场对照时，右侧队伍的 A / C 对应左侧视角的 C / A。
