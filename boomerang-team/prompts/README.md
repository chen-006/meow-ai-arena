# 提示词和通知原文

第 12 集主办方发给两位队长和八名队员的全部消息。模板文件开头的引用块是开源时加的说明（什么时候发、花括号怎么填），两条分隔线 `---` 之间才是发出去的原文。主办方本机的工作目录一律写成 `{WORKDIR}`。

## 按比赛顺序

| 文件 | 发给谁 | 什么时候 |
|---|---|---|
| [`开赛_队长.md`](开赛_队长.md) | 两位队长 | 开发开始（120 分钟）；原文也贴在上一层的 [`prompt.md`](../prompt.md) |
| [`队长须知模板.md`](队长须知模板.md) | 两位队长 | 开赛时放在队长文件夹里的 `队长须知.md`：`ask.cmd` 派活、`亲手改.cmd`、交布阵的用法 |
| [`开赛_队员.md`](开赛_队员.md) | 八名队员 | 开发期间每次被派活，自动附在任务书前面 |
| [`开发结束_代码冻结.md`](开发结束_代码冻结.md) | 两位队长 | 开发截止、代码封存后 |
| [`回合开始.md`](回合开始.md) | 两位队长 | 每回合 15 分钟决策时间开始时（含每回合的模式说明） |
| [`前言_商量.txt`](前言_商量.txt) | 八名队员 | 决策时间里被叫来商量，自动附在任务书前面 |
| [`回合结果.md`](回合结果.md) | 两位队长 | 每回合对局打完后，和下一回合的"回合开始"同一条消息 |
| [`比赛结束.md`](比赛结束.md) | 两位队长 | 第 6 回合结果之后，请队长写赛后复盘 |
| [`队员赛后复盘提示.txt`](队员赛后复盘提示.txt) | 八名队员 | 赛后由主办方直接发给每个人（不经队长），实发原文 |

## 比赛期间的临时通知（[`主办方通知/`](主办方通知/)）

开发阶段出了两件事，主办方各发了一条通知，原文照收。来龙去脉也写在 [`../CONDITIONS.md`](../CONDITIONS.md) 的"中断和事故"一节。

| 文件 | 发给谁 | 起因 |
|---|---|---|
| [`Astra队_第1条_Kimi修复.txt`](主办方通知/Astra队_第1条_Kimi修复.txt) | Astra 队队长 | 开发一开始，Kimi 的读文件、运行命令工具因主办方赛前准备的问题不可用；队长在等修复期间用掉一次亲手改替 Kimi 改了程序。故障修好后通知队长可以照常派活，那次亲手改退还次数、改动保留 |
| [`Astra队_放宽单次任务上限.txt`](主办方通知/Astra队_放宽单次任务上限.txt)、[`Fable队_放宽单次任务上限.txt`](主办方通知/Fable队_放宽单次任务上限.txt) | 两位队长（内容相同） | 派活工具原来给队员的单次任务设了 30 分钟上限，开发前半段两队都有任务被它结束（派活记录里显示"超时"）；之后把上限放宽到开发截止时刻 |
