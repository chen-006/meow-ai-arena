# 比赛提示词与通知原文

本目录收录第 12 集 5v5 回旋镖团队赛发给两位队长与八名队员的全部提示词模板及比赛期间发出的主办方通知（仅将主办方本机绝对路径替换为 `{WORKDIR}` / `{赛事目录}`）。

| 文件 | 说明 |
|---|---|
| `开赛_队长.md` | 开发阶段发给两位队长的开赛提示词模板 |
| `开赛_队员.md` | 开发阶段每次派活自动附在任务书前的队员说明 |
| `队长须知模板.md` | 队长工作目录下的使用手册（`ask.cmd`、亲手改、布阵提交规则） |
| `开发结束_代码冻结.md` | 120 分钟开发截止、代码冻结通知模板 |
| `回合开始.md` | 第 1～6 回合（及加赛）布阵决策窗口开始通知模板 |
| `前言_商量.txt` | 回合决策阶段叫队员商量时附在任务书前的说明 |
| `回合结果.md` | 每回合对局结束后发给两位队长的结果模板 |
| `比赛结束.md` | 赛后发给队长和队员的复盘提示词模板 |
| `队员赛后复盘提示.txt` | 赛后实发给八名队员的复盘提示词原文 |
| `主办方通知/` | 比赛期间实际下发给队长的临时通知（Kimi 环境修复与单次任务上限调整） |
