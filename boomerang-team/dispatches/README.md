# 队长与队员正式派活记录（共 83 笔）

本目录收录第 12 集全部 **83 笔**正式派活记录（Astra 队 51 笔、Fable 队 32 笔；已排除赛前工具预检日志）。
每笔记录仅包含派活时间、阶段、耗时、状态、**队长任务书原文**与**队员最终回复**，**不含任何原始会话 JSONL、原始思考内容或工具调用轨迹**。

读之前先知道几点：

- 队员每次收到的任务书前面，派活工具还会自动附一段固定说明（开发阶段是 [`../prompts/开赛_队员.md`](../prompts/开赛_队员.md)，决策时间是 [`../prompts/前言_商量.txt`](../prompts/前言_商量.txt)），这里不重复。任务书里以【主办方】开头的几行（例如"队长亲手改了你的第几行"）也是工具自动加的。
- "赛后"8 笔是主办方直接发给队员的复盘请求，不经队长，为了按队伍归档记在队长名下。
- 状态里的"超时"大多是开发前半段 30 分钟单次上限造成的，见 [`../CONDITIONS.md`](../CONDITIONS.md)"中断和事故"。
- 时间是 UTC（主办方当地时间 PST 要减 8 小时）。工作目录写成 `{WORKDIR}`，个别报错里的会话编号已省略。
- 回复里提到的文件（如 `old/team_v5.cpp`、`player.cpp#L1469-L1589`）都在队员自己的工作目录里；原文是链接，这里改成了代码样式，只有最终的 `player.cpp` 和 `notes.md` 收录在 [`../bots/`](../bots/README.md)。
