飞镖乱斗 · 回放查看器
视角：

把回放文件拖到这里

回放是裁判或对战器写出的文本文件（第一行是 DART-REPLAY 2，一般是 .txt）。

也可以点下面的按钮选择文件。加载后按空格播放，点右侧事件可以直接跳到那一步。

按键

空格 播放 / 暂停　← → 单步　Shift+←→ 跳 1 秒
[ ] 调慢 / 调快　, . 上 / 下一个出局　Home End 到开头 / 结尾　D 调试信息
滚轮缩放、拖动平移、双击画面复位；点右侧表格里的角色可高亮他。

图例

墙　坑　草丛　红色闪烁 = 即将塌陷（预警）
圆 = 角色（体内数字是座位号，白色三角 = 朝向，队伍颜色圈 = 队伍）。
回旋镖：实线拖尾 = 去程；虚线拖尾 + 连线回到主人 = 回程；金色 = 召回飞行；落地的镖颜色变暗。
两把镖在空中相撞：白黄色星形火花 + “相撞”，两把镖随后落地。
冲刺：身体拉长、带拖影和速度线，可以越过坑。橙色扇形 = 挥砍，紫色扇形 = 踢（判定那一步）。
星星绕头 = 被踢硬直；半透明 = 在草丛里对手看不见。
出局：叉 + 角标（镖 / 砍 / 坑）；落坑的会缩小消失；红线从凶手连到死者。
