# 版本演化：每个模型是越改越强，还是越改越差？（三个游戏对比）

方法：从会话记录重放每位选手的代码修改，取每次编译/运行时的快照作为历史版本（每人按时间均匀取最多 7 个）；
固定对手池（基准 + 全员交卷版）挑战赛，历史版本只与对手池同局、彼此不相遇；交卷版也以挑战者身份再测一遍，同一行可直接比较。
详表：`ctf/appendix/version-evolution.md`、`bomberman/appendix/version-evolution.md`、`land/appendix/version-evolution.md`。会话记录本身不公开。

## 观察
- 炸弹人：强模型几乎单调变强（Astra 223→371、Sol 119→274，交卷即最强）。规则直观、局面反馈清晰，本地自测和真实强度一致。
- 夺旗：几乎没人单调变强，多数人中途某版最强；只有 Opus、Sonnet 交卷版最强。博弈性强，自测（常是对自己/对基准）容易过拟合。
- 圈地：波动最大。Sol 00:51 就到 271，之后一度掉到 -248，交卷 142；Opus 第一版 288，中途掉到 190 多，最后改回 310。
- 国产模型的普遍模式：中途冲高再回落，交卷版常不是最强（Kimi 炸弹人 13:28 达 240，交卷 186）。
- 圈地 Astra 前 4 个版本（02:51–03:11）每局都崩溃：Bot 对象放在栈上，Windows 默认 1MB 栈溢出。已用原赛官方编译参数（-O2 -std=c++20 -static）复测确认是真 bug，03:19 版改成 make_unique 后修好，实力直接从 -227 跳到 252。
- 炸弹人 Qwen 第一个版本 48 局全故障；豆包第二版就到顶，之后 20 多分钟原地踏步。
