# 评分方法

三集都用 Bradley–Terry（BT）模型，把每局比赛拆成"两两谁赢了谁"，拟合出每个选手的实力值。差别在于怎么拆分、怎么换算刻度：

| | 第 1 集 圈地 | 第 2 集 炸弹人 | 第 3 集 夺旗 |
|---|---|---|---|
| 一局怎么判 | 按领地格数排名 | 单局分 = 生存分 + 0.5 × 击杀份额 | 按交旗数排名 |
| 拆成两两比较 | 单挑直接算；4 人混战拆成 6 组 | 按名次拆，平局算半胜 | 按名次拆，平局算半胜 |
| 不同人数怎么加权 | 单挑、混战各拟合一次，各占一半 | 2–10 人每档总权重相等 | 2–15 人每档总权重相等 |
| 0 分是谁 | greedy 基准 | 公开基准 | 公开基准 |
| 刻度 | 该赛制最强模型 = 100，低于基准记 0，总分再把第一换算成 100 | 400 × log10(实力 / 基准实力)，不封顶 | 400 × log10(实力 / 基准实力)，不封顶 |
| 脚本 | `land/tournament/rate.py` | `bomberman/tournament/bt.py` | `arena/bt.py` |

"400 × log10" 的意思是：比对手强 10 倍（期望胜率约 91%）记 +400 分，强 3 倍约 +190 分，旗鼓相当是 0 分。

- 区间：第 1、3 集用重抽样（bootstrap）给出 95% 区间；第 2 集不生成区间。
- 每对交过手的选手额外加一局虚拟平局，避免全胜或全负时估计发散。
- 实力值依赖对手池和人数构成。即使是同一集，换一个对手池重测，数值也会变（`docs/version-evolution.md` 里的挑战赛就是例子），只有同一张表内的分数可以互相比较。
