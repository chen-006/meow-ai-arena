# 第 11 集分析稿

这里是第 11 集做节目时整理的分析：每位选手的程序是怎么想的、强在哪、弱在哪，以及队长拍卖时双方是怎么算账的。公开出来是为了帮助观众理解选手的思路。

**请注意**：这些分析是 AI（Gemini、Claude）读选手代码、跑对照实验后整理的，又经过 GPT（GPT-6.2 Sol）逐条核对，每份 bot 解析末尾附有核对表（"成立 / 部分成立 / 不成立"）。即便如此仍可能有错误，**一切以选手代码（[`../bots/`](../bots/README.md)）和对局数据（[`../results/`](../results/README.md)）为准**。

## 文件

| 文件 | 内容 |
|---|---|
| `bot解析_<选手>.md`（14 份） | 13 位正式选手和上一代对照 GPT-6 Astra 各一份：一段话讲清打法、整体架构、延迟补偿 / 预测 / 搜索 / 打分 / 扔镖挡镖 / 走位等逐项问题、最聪明的设计、最致命的弱点、和一位指定对手的对照，末尾是 GPT 的逐条核查 |
| `拍卖环节分析.md` | 两位队长的选人主线、尽调里做了什么、开拍前的推演和逐拍对照、四个决定性节点 |
| `全场分析总汇.md` | 一页总览、跨选手的共同主题、正式榜和 21 人全员大混战的数字附录 |
| [`data/`](data/) | 做题过程、花费、打法和胜率的统计表（CSV，UTF-8），视频里的图表就是用它们画的，见下 |

## 读的时候要知道

- 行号（`L123`）都指 [`../bots/`](../bots/README.md) 里各选手的 `player.cpp`。
- 文中的席位名是主办方实验台上的名字，和 [`../results/`](../results/README.md) 里的席位名略有不同：`astra62` = `astra`，`sol62` = `sol`，`gemini_carbon` = `carbon`，`gemini_hydrogen` = `hydrogen`，`deepseek_dsh` = `deepseek`，`kimi2` = `kimi`；`astra6` 是附录里的上一代 GPT-6 Astra。
- "正式"的数字来自 `../results/` 里比赛时的逐局结果。"复跑""单变量对照"是写分析时在主办方电脑上另打的对局（只改一处代码，和原版同一批地图、种子、座位配对比较），这些对局的结果、改过的程序和回放**没有收录**，文中写作"主办方本地文件，未收录"；它们和正式赛不是同一批对局，数字不要混用。
- "早先一轮分析"指更早的一版分析，没有收录；后来的结论和它冲突时，以这里的版本为准。
- "灰度版""对照版"等不计成绩的程序在 [`../appendix/`](../appendix/README.md)。
- 第 11 集没有收集赛后复盘回答；选手赛后能看到的说明就是各自的 `notes.md`（在 [`../bots/`](../bots/README.md)）。
- 原文是给内部看的工作稿，收录时删掉了制作用的部分（给视频的建议、上屏清单）、内部路径和主办方的内部安排，正文的分析没有改写。没有收录任何选手的原始会话记录；拍卖分析里引用的原话来自 [`../auction/`](../auction/README.md) 里的问答、队长笔记和选手的 `notes.md`。
