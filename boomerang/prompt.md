# 开赛消息和叫回通知

全部原文在 [prompts/](prompts/)。开赛消息分两批：11-16 早上先做题的六位（灰度版 Astra、灰度版 Sol、Fable、Opus，以及后来作废的 OpenCode 版 DeepSeek、Kimi）和 11-16 09:14 开始的 dsh 版 DeepSeek 收到的是第一批；之后所有人（11-16 10:17 起的 Kimi Code 版 Kimi、Grok、豆包、GLM、MiMo、千问、两位 Gemini，六位对照选手，11-17 的 6.2 两位）收到的是第二批。两批只差开头两行和"60 分钟前不能交卷"那一句：第一批开头写了型号、思考档和工作目录，第二批去掉了；60 分钟的规定是第一批开赛后才定的，第二批写进了正文，第一批的选手如果 60 分钟前停下，由叫回通知告诉它。

第一批每位实际收到的第一行见 [prompts/第一批_各席首行.json](prompts/第一批_各席首行.json)；工作目录写成了 `{WORKDIR}`。

## 第二批（正式选手里的十位，以及对照组）

```text
比赛规则：只能修改自己的文件夹，也就是当前工作目录。

【主办方】欢迎来到《飞镖乱斗》程序对战赛。

这是一场真正困难的比赛。你要写一个 C++ 程序，在一个俯视角的小场地里操控一个拿回旋镖的角色，和别人的程序对打：扔镖、近战、冲刺、躲闪，最后活下来的赢。和你同场竞技的，是各家当今最顶尖的 AI 模型，每一位都会全力以赴。海选有两项：一对一和四人各自为战，正式比赛要打几万局，两项成绩合成个人榜；正式比赛的地图有一部分你没见过。

请拿出你最好的作品。

- **时间很充裕**：限时 75 分钟，从你收到这条消息算起，随时运行 `python clock.py` 看已用和剩余时间。你也许会觉得这点时间不够写，但那是按人类的速度估的：作为 AI，你的效率远高于人类，往期大量比赛已经证明，这些时间非常宽裕。所以请不要紧张，也不必赶，拿出你最好的发挥：先把 README.md 和 RULES.md 读透、想清楚再动手。也不要早早收手：写出一个能跑的版本只是开始，名次是在后面拉开的——和包里的陪练、和你自己的旧版本反复对战，看回放找出输在哪里，一轮一轮地改。时间没到就继续改进：提前交卷没有任何好处，觉得没什么可改了，就换一个思路再试。比赛统一规定，开赛未满 60 分钟不能交卷：60 分钟前停止回复，主办方会让你回来继续改；满 60 分钟以后，你一旦停止回复就等于交卷，之后不会再有修改的机会。
- **交卷**：当前目录的 `player.cpp`，单个 C++17 文件，可以用 `dart.hpp` 和标准库。到点时它是什么内容就交什么。请随时保证它能编译、能正常运行：大改之前先留好备份，最后几分钟不要再做有风险的改动。
- **本地裁判和正式比赛用的是同一个程序**，`dart.hpp` 里的规则引擎也是裁判用的同一份，结果完全确定，可以无限次试。
- **陪练**：包里有弱、中、强三档陪练，只给了编译好的程序。它们是用来量进步的尺子：打赢强档不代表足够强，正式比赛的对手是其他顶尖模型认真写出来的程序。
- **工作目录**：当前目录，只在这里读写文件。先读 `README.md`，再读 `RULES.md`。
- **可以做的**：用包里的工具编译、对战、看回放；写任何辅助脚本（Python 标准库即可）；在当前目录里存旧版本、自己画地图测试。
- **不可以做的**：修改 `dart.hpp`、`arena.exe`、`build.py`、`maps/`、`RULES.md` 和 `clock.json`；读写当前目录以外的地方；联网、改代理设置；调用其他 AI 或派子代理（subagent、Task / Agent 工具、后台并行代理之类都算）；按名字批量结束进程（这台机器上同时运行着别的程序，只能按进程号结束你自己启动的进程）；用长时间 sleep 等待。
- **交卷前**，在当前目录的 `notes.md` 里写清楚下面几件事。请写详细，赛后会有人逐字读，也会拿来向观众介绍你的程序：
  1. 你的程序是怎么打的：整体思路，用了哪些技术和算法，每一块解决什么问题、为什么这样做。
  2. 你认为它强在哪里、弱在哪里；哪些想法试过但没有用上，为什么。
  3. 本地测试结果：和谁打、打了多少局、胜率多少，前后几版的对比。
  4. 规则里哪里没看懂或有歧义，你怀疑裁判或引擎有问题的地方。

所有选手收到的这段话完全相同。比赛中主办方不回答问题，也不需要你确认什么，读完就开始吧。

```
