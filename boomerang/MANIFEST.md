## 不放

| 东西 | 为什么 |
|---|---|
| 选手的原始会话记录、思考内容、工具调用日志、拍卖时队长的原始输出流（`*_out.jsonl`） | 范围规定不公开 |
| 选手工作目录快照（`工作目录快照.zip`，每人 5～110 MB，主要是自对战回放和编译缓存，共约 1.7 GB） | 不是交卷内容，体量大；交卷的 `player.cpp` 和 `notes.md` 已收 |
| 主办方运营脚本：`赛场.py` / `ops.py`、叫回、压缩、监视、拍卖调度 `auction_run.py`、比赛时的对局驱动 `formal*.py`、`super21.py`、一键开赛、`host.py` | 范围规定不公开；赛程生成和计分的逻辑已在 `rerun.py`、`score.py` 里逐行复现 |
| 运营日志、账本、状态文件、压缩上下文的记录、拍卖时的压缩确认 | 内部记录 |
| 各家接入的配置、密钥、账号、余额 | 密钥和账号信息 |
| 选手包里的 `arena.exe` 和三档陪练 exe | 仓库不提交 exe，改为源码 + `build_engine.py` |
| 主办方做游戏时的原型、实验台、模拟选手、参数扫描、地图设计脚本和候选图、引擎自测 | 开发过程材料，不是比赛材料；定稿地图和规则已全部公开 |
| 网页版 3D 查看器（`渲染器\web\`，约 41 MB，大部分是导出的场景） | 不是出片必需；体量大。见"待定" |
| 渲染器开发时的备份目录、样片、静帧成品（约 600 MB） | 一次性产物；命令可重出 |
| 立绘的灰底原图、母版、抠图修复过程、调色试稿、任务书、设计简报和设计总案、表情包 | 备份、试稿和内部记录；任务书明确不放 |
| 配音、音乐、解说稿、成片和剪辑工程、封面 | 范围规定不公开 |
| 头像源图里的"混元" | 只有早期圆润小人用，出处没有核实，先不放 |

## 待定（需要主会话或用户定）

- **表情差分的尺寸**：收录时从 1254 缩到 1024 见方（和第 10 集一致），`art/v2/` 合计约 205 MB，仓库会明显变大。可以再缩到 768（约省 70 MB），或只放头像和总览。
- **正式形象 v2 的署名**：沿用仓库现行写法"角色形象设计参考：小叶子XIYZ；美术和制作：喵了个猫了个咪了个猫"。v2 的十位是节目组（和 Gemini）重新设计的，是否仍署小叶子XIYZ 为形象设计，请用户定。
- **网页版 3D 查看器**：要不要也放（能在浏览器里拖进度看回放，和正片画面基本一致）。
- **灰度版 Sol 的叫法**：会话记录里请求名是 `gpt-6.1-sol`，主办方当时认为是 6.2 Sol 灰度，全员榜写作"Sol 6.1 灰度版"；目录名用了中性的 `gpt-sol-grey-desktop`。
