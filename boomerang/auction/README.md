# 队长拍卖

海选之后，第一、第二名当队长，用 1000 元预算暗标买队员，为下一集的团队赛（4 对 4，每队五人、每张图上场四位）组队。这一集到拍卖为止。

## 规则（正式拍卖第一条消息里的原文要点）

- 队伍 = 队长 + 同门（GPT-6.2 Astra 带 GPT-6.2 Sol，Claude Fable 5.2 带 Claude Opus 5.5，直接入队）+ 拍卖买 3 人。
- 候选 9 位，按海选名次从高到低逐个上拍，最后 3 位落选。每位队长 1000 元，要买满 3 人。
- 每次两位队长各报一个价，互相看不到，附一句理由。价高的买下，按自己报的价付钱。报 0 表示不要；两人都报 0 就落选。
- 同价重报，最多三次；还相同，剩余预算多的一方买下，再相同比缺人多少，再相同按固定抽签。
- 每次最多能报的数（`ceiling`）要给每个还空着的名额留 1 元。剩下的候选人数等于两队还缺的人数时不能再放弃。一方买满就退出，另一方之后每人 1 元。
- 上一位候选人双方的出价，之后对两位队长公开；理由不互相公开。
- 开拍前 10 分钟尽调：只读文件夹里有海选成绩表和九位候选人的程序、笔记；可以自己跑程序做实验，不能改材料，也不能改自己的 `player.cpp`。规则程序是 [auction.py](auction.py)。

## 结果（11-17 正式拍卖）

| 队伍 | 买到的人（价格） | 花费 | 余额 |
|---|---|---:|---:|
| GPT-6.2 Astra 队（+ GPT-6.2 Sol） | Gemini 4 Hydrogen（400）、Grok 4.7（400）、Kimi K3.1 Pro（1） | 801 | 199 |
| Claude Fable 5.2 队（+ Claude Opus 5.5） | Gemini 4 Carbon（599）、GLM 5.3（200）、DeepSeek-V4.1-Flash（201） | 1000 | 0 |

落选：千问、MiMo、豆包。逐轮出价和理由在 [拍卖结果.md](拍卖结果.md)（`.json` 是程序读的同一份）。
