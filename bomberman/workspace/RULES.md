# 炸弹人规则 v0.5-public-state（公开）

## 目标与行动

每人控制一个角色，争取最高的生存与击杀合计分。每回合所有存活玩家看到相同的完整公开状态，独立选择 U/D/L/R/S（上下左右/等待）与放弹位 0/1。没有攻击按钮、装备、道具、生命值或复活。角色被爆炸、残留火焰、缩圈击中即淘汰。

坐标从 0 开始，左上角 (0,0)，x 向右，y 向下。`#` 永久墙，`+` 可破坏箱子，`.` 空地。玩家不能重叠；允许相邻两人同时交换位置，也允许多人形成移动环。不因碰撞死亡。非法地形移动原地停留，方向可以直接反向。

所有人数：炸弹容量 2，爆炸射程 3 格（不含中心），引信 4 回合，火焰覆盖爆炸回合及下一回合。绝对行动回合 t 从 0 开始；t 放的炸弹在 t+4 的爆炸阶段引爆。放弹在原位置，随后移动；放弹和移动可以同回合执行。

## 地图

外圈为永久墙；内部 x、y 同为偶数的格子也是永久墙。其余格子按生成器以 0.42 概率放箱子；出生点曼哈顿距离2内不放箱子。出生位置至少两条初始可走出口，清除箱子后的道路连通。箱子分布开局公开，对局过程无随机数。

2 人出生在对角，地图180°对称；4人在四角，地图90°对称。其他人数在内侧边界的奇坐标位置环上等距取点（整数取整），种子决定起点，箱子独立生成。这些人数不保证单局出生点完全等价。地图生成代码见 `make_map()`。

## 一回合的精确阶段

输入是本回合开始、尚未执行以下阶段的状态。按顺序处理：

1. **清理和缩圈**：删除已过期火焰；所有协议错误/超时玩家同回合淘汰；到缩圈回合时，将距外边界不大于新层数的格子变成永久墙。首缩是层1（原外墙层0）。新墙上的玩家立即死亡，不能在该回合移动逃出。新墙上的炸弹直接移除，不爆炸；箱子和火焰也移除。
2. **放弹**：在玩家移动前的位置尝试放置。存活、当前位置无炸弹、自己的在场炸弹少于2，才有资格。多个有资格玩家在同格同时请求放弹时，所有请求失败，避免按 ID 偏袒。没资格的请求不参与冲突。放弹失败不影响移动，也不算协议错误。本回合即将爆炸的旧炸弹仍占用容量。
3. **移动**：上下左右移动一格或等待，所有玩家同时处理。墙、箱子、炸弹阻挡进入；被阻挡则原地停留。玩家可站在脚下原有/刚放的炸弹上等待，也可以离开；离开后不可走回仍有炸弹的格子。地形判定后，若多个玩家的目标相同（包括等待者的当前位置），这些玩家全部停留。随后若某人的目标被已停留者占用，他也停留，反复传播直至稳定。其余移动同时成功，包括两人交换、多人成环、跟随离开的玩家。没有按 ID 抢占的优先级。
4. **爆炸**：计时到期或处于旧火焰上的炸弹引爆，向四方向延伸最多3格。永久墙阻断且不着火；箱子格着火、箱子被毁，但阻断继续传播；炸弹格着火、立即连锁引爆，同时阻断这一条射线。所有爆炸统一使用本阶段开始时的箱子/炸弹分布：先炸掉箱子不让本回合另一股火焰穿过去，先爆炸的炸弹仍是这个阶段其他射线的阻挡物。
5. **火焰与淘汰**：删除引爆炸弹，移除被炸箱子，火焰在爆炸回合 t 和 t+1 有效。移动结束后处于旧/新火焰的玩家同时淘汰。死者已放的炸弹保留、继续计时，除非后来被缩圈删除。然后回合数加1。

所有阶段执行完整后才判断结束。即使缩圈后只剩一人，他仍需经受本回合爆炸；可以最终无人存活。同回合不同阶段死亡者仍并列。

## 结束与排名

存活人数≤1，或达到回合上限，结束。单局分 = 生存分 + 0.5 × 击杀份额。

- 生存分：每多活过一名对手得 1 分；与一名对手同回合淘汰或同为终局幸存者，彼此各得 0.5 分。终局幸存者比所有死者晚淘汰。设人数为 n、生存名次为 r、该名次人数为 t，则生存分为 `n-r-(t-1)/2`。
- 击杀份额：死者所在格的有效火焰按炸弹原主人归属，排除死者本人，不同主人均分一个击杀。同一主人多股火焰只算一次；连锁爆炸不转移下游炸弹归属；旧火焰保留来源；已死亡的主人仍可获份额。缩圈、协议错误、仅自身火焰造成的死亡没有击杀份额。
- 按单局分从高到低排名，同分并列，不另设破平条件。名次为 `1 + 分数严格高于自己的玩家数`。裁判使用精确分数比较；最后幸存者不保证单局第一。

例如五人局：第二名生存分 3，独占三个击杀得 1.5，合计 4.5；零击杀的最后幸存者得 4 分。

放弹数、破箱数仅展示，不计分。一个箱子同回合被多个玩家炸到时，每个命中的玩家都记一次破箱。

正式赛按单局排名转换为两两胜负，平局计半胜，用 Bradley–Terry 模型拟合实力。不同参赛人数的比赛总权重相等，公开基准锚定 0；不按当期最高分重新缩放。

本届九位选手及一个公开基准参加2、5、10人三档比赛，各档总权重为1/3，每档20张地图。双人全配对并交换座位；五人平衡分组并正反轮换座位；十人全员正反轮换座位。合计2600局，各选手960局。五人赛每对选手交手80、90或100局，各选手总出场及各座位次数相同。

BT 显示值为 `400×log10(选手实力/基准实力)`，弱于基准显示负值。每对已交手选手在加权统计后加入一次虚拟平局，使全胜或全负也得到有限估计。

## 文本协议

进程启动后仅一次：

```text
INIT 边长 玩家数 自己ID 回合上限 引信 射程 容量 火焰回合数 首缩回合 缩圈间隔
```

每回合：

```text
TURN t
BOARD
...（边长行，字符 # + .）
P id x y alive
...（玩家数行，alive为0/1，ID从0起）
BOMBS k
B owner x y explode_at
...（k行，explode_at为绝对行动回合）
FLAMES f
F x y last_lethal_turn
...（f行，最后致命回合含端点）
STATUS 玩家数
S id death_turn kill_numerator kill_denominator
...（玩家数行；存活者death_turn为-1，击杀份额为精确分数）
SOURCES s
O x y owner last_lethal_turn
...（s行；当前仍有效的每格火焰来源，每位主人一行）
END
```

STATUS 是截至本次输入的累计击杀份额与淘汰回合；SOURCES 保留各主人各自的火焰到期时间。所有选手接收相同公开状态，自身ID由INIT指定。必须读取至END后再回答。

回答恰一行，单空格分隔：`t U 0`。大写 U/D/L/R/S；0/1；行尾换行并 flush。支持 LF/CRLF，每行最多256字节。禁止提前输出未来回合，禁止 stdout 调试内容，非法输出或超时立即淘汰。

首回合2000ms，之后每回合50ms。从开始发送输入到完整回答行抵达计时，包含输入输出和系统调度；进程创建时间不计入首回合预算。

程序超时、退出或违反输出协议时淘汰。
