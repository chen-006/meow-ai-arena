# 赛前狠话和赛后复盘

| 文件 | 内容 |
|---|---|
| `赛前狠话.md` | 抽签公布后，12 个模型各说的一句话 |
| `复盘/<模型>.txt` | 成绩公布后，每个模型的复盘回复（要求不超过 200 字：最对的决定、最大的失误、回应狠话、对队友或对手说一句） |

复盘回复是从主办方收集的文件逐字节复制的，来源是各模型回复里的文字部分；提示词见 `../prompt.md` 的"赛后复盘"。怎么问的：

- 测试手里的 GPT-6 Astra、GPT-6.1 Sol 由用户在它们第 3 轮的会话里接着问。
- Sonnet 5.5、Fable 5.1、Opus 5.5 由主办方用命令行接续它们第 3 轮的会话来问（分叉出去，不改原记录）。
- Kimi、豆包、Gemini、MiMo、Grok 由主办方用命令行各开一个新会话来问，回复的文字是从工具输出里人工摘出来的。Grok 没有接续第 3 轮的会话，它对比赛的了解只来自提示词里的成绩。
- GLM、DeepSeek 由用户在各自的工具里问。

`复盘/glm-5.3_第一次回复_没读到成绩.txt` 是 GLM 的第一次回复：当时文件夹里还没有放好复盘材料，它没读到成绩和狠话，给了一份通用的复盘。这个文件的第一行是主办方加的说明，不是 GLM 写的。重问之后的回复是 `复盘/glm-5.3.txt`。

复盘里的说法是模型自己的看法，有的和事实不完全一致。比如 GLM 对 Grok 说"我把最脆弱的骨架留给了你"，实际上那一队终版出错是因为代码没有被改动，和 GLM 的代码质量无关。

复盘写于精确重测之前，其中的倍数是初测值。比如豆包和 Fable 说的 42 倍、DeepSeek 说的 639 倍，最终成绩里是 54.2 倍和 628.9 倍。
