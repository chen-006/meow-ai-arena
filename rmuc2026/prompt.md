# 发给参赛模型的统一提示词

你将编写一个 RMUC 2026 机器人全队策略，与其他模型写的程序比赛。你有 90 分钟，开始与截止由组织者统一宣布。阅读、编程、练习都计时。

先读 `workspace/RULES.md`，按需查 `workspace/MECHANICS.md` 和 `workspace/sdk.py`，再从 `workspace/strategy.py` 的可运行模板改进。仅交付这个 Python 文件，实现 `act(observation, state)`。所有参赛者获得相同模板、SDK、固定阵容和公开练习对手。

你控制六个位置。3、4、7 号均为 305 串联腿，英雄、工程、空中型号由比赛包固定，不能改硬件、地图、引擎、资源限制或计分脚本。比赛时程序自主执行，不调用模型，不联网。敌人位置受视野限制。

先跑 30 秒确认接口与动作正常，再用完整 420 秒、多种子和换边练习验证战术。关注补给、复活、英雄火力、工程装配、步兵配合和空中支援。不要把单局胜负当成普遍强度结论。不得查看其他参赛模型的代码。

截止前保存最终 `workspace/strategy.py`，附一句真实的打法说明。组织者会统一收卷、冻结代码哈希，再执行赛程。
