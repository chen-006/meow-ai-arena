# 对照实验：同一个 DeepSeek，换工具差多少（不计正式成绩）

同一个模型（DeepSeek 官方 API，V4.1 Flash，最高思考档）、同一份选手包、同一句提示词，只换 agent 工具或模式，各做一次。四份代码与基准同场打了 616 局（2–15 方各人数等权）：

| 文件 | 工具 | 实力值（基准 = 0） | 95% 区间 | 用时 |
|---|---|---:|---|---|
| `dsh-standard.cpp` | dsh 0.2.0-rc.2（DeepSeek 官方工具），标准模式 | **+124** | 105 ~ 147 | 35 分钟 |
| `dsh-minimal.cpp` | dsh 0.2.0-rc.2，极简模式 | +32 | 9 ~ 53 | 55 分钟 |
| `opencode.cpp` | OpenCode | −2 | −25 ~ 22 | 54 分钟 |
| `zcode.cpp` | ZCode | −7 | −29 ~ 14 | 67 分钟 |

- 只切换 dsh 的"模式"一个开关就差了约 90 分。极简模式只有一个终端，没有专门的读写文件工具、后台任务和上下文压缩。
- 每个工具只跑了一次，单次结果波动很大（上一期炸弹人里 ZCode 远强于 dsh），不能据此断言哪个工具一定更强。
- 因为这个结果，正式赛定下原则：**各家模型都用自家工具**。所以 DeepSeek 的正式成绩用的是 `dsh-standard.cpp`（即 `../../bots/deepseek-v4.1-flash.cpp`）。
