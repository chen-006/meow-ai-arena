# 多阵营夺旗 · 规则 v1.0

2–15 个阵营同场，每个阵营由一个程序控制 3 个角色。把中立旗送回自己的基地，每送回一面得 1 分。400 回合后按得分排名，同分并列。

## 地图

- 正方形格子地图，边长：2 方 23，3–5 方 31，6–10 方 41，11–15 方 49。四周是墙，场内散布单格柱子，也是墙。整张地图公开。
- **基地**：每个阵营一块 3×3 区域。所有基地排成一圈，到地图中心的距离相同，相邻基地的间距大致相等。任何角色都可以走进任何基地。
- **旗点**：每个基地前方各一个，再加地图正中心一个，共"阵营数 + 1"个。每个基地到自家旗点、到中心的距离都相同。
- **旗子**：共 max(2, ⌈阵营数 / 2⌉) 面，没有归属。开局和每次回位时，旗子随机出现在一个没有旗子的旗点上。这个随机与地图生成无关，无法预测。

## 每回合

每个角色选一个**移动**（上、下、左、右、不动）和一个**动作**（攻击、拾旗、丢旗、不做事）。所有程序同时提交，然后按下面的顺序结算：

1. 到时间的旗子回位，到时间的阵亡角色重生
2. 移动
3. 攻击，阵亡
4. 拾旗
5. 丢旗
6. 交旗

### 移动

上下左右走一格，或原地不动。走向墙等于不动。结算后任何两个角色都不在同一格：

- 多个角色要进同一格：都不动。
- 走进别人正在离开的格子：可以；如果对方没走成，你也不动。
- 两个角色对换位置：同阵营可以；不同阵营都不动。
- 三个及以上角色绕圈移动：可以。

### 攻击

- 攻击要指定目标（敌方角色的 id），按双方移动后的位置判断能否打到。
- 射程：横纵距离之和不超过 2。墙的遮挡只有两种情况：隔一格直线攻击（如横向相距 2）时，中间那格不能是墙；斜向攻击（横纵各差 1）时，两个拐角格至少有一个不是墙。紧挨着的攻击不受墙影响。
- 每次命中造成 34 点伤害。生命值 100，不会自然回复，所以 3 次命中必定阵亡。
- 所有攻击同时生效，双方可以同回合互相击杀。
- 携旗的角色不能攻击。刚重生的角色，在重生的那个回合既不能攻击，也不会被攻击。

### 旗子

- 拾旗：和旗子在同一格时拿起。每人最多拿一面；同一格有几面时拿编号最小的。
- 携旗角色阵亡时，旗子掉在原地，任何阵营都能捡。
- 丢旗：主动放下旗子。拾旗先于丢旗结算，所以队友最早下一回合才能捡起。
- 地上的旗子 15 回合无人拾取，会回到一个随机的空旗点。
- 回合结束时携旗角色站在自己的基地里，即交旗得 1 分。这面旗离场 8 回合后，重新出现在一个随机的空旗点。

### 阵亡与重生

阵亡 10 回合后在自己的基地重生，满血，优先占离地图中心近的空格；基地被站满（包括被敌人站住）时推迟到有空格为止。可以提前给即将重生的角色下指令，它在重生的那个回合就会移动和拾旗。

## 程序接口

- **语言**：C++20，只能用标准库。提交一个文件 `submission/bot.cpp`，用 `g++ -std=c++20 -O2` 编译（Windows 另加 `-static`）。
- **通信**：每回合从标准输入读一个文本块，向标准输出写一行回复，写完立即刷新（例如用 `endl`）。程序在整局比赛中持续运行，可以在内存里保存状态。调试信息写到标准错误。
- **时限**：第一回合 2 秒（含程序启动），之后每回合 50 毫秒，从发出输入到收到完整回复计时。超时或回复格式错误时，这一回合按全部原地不动处理，迟到的回复会被丢弃。连续失败 3 次，或者程序退出，本局剩余回合都按原地不动处理。
- 程序只能通过标准输入输出与裁判通信，不得读写文件、联网或启动其他程序。

`submission/bot.cpp` 模板已经写好了完整的输入解析，可以直接沿用。

### 输入

第一回合先收到一次开局信息，之后每回合收到一个以 `END` 结尾的块。数字之间用空格分隔，每项占一行：

```text
INIT 阵营数 你的阵营 地图边长 总回合数 生命 伤害 重生回合数 旗子无人拾取回位回合数 交旗后离场回合数
MAP
（地图边长行，# 墙，. 空地）
BASES 阵营数
x y                    （每行一个阵营的基地中心，基地是以它为中心的 3×3）
SPOTS 旗点数
x y                    （每行一个旗点）
```

```text
TURN t                 （即将结算的回合，从 1 开始）
SCORE 各阵营得分
UNITS 角色数
U id 阵营 x y 生命 携带的旗 重生回合
FLAGS 旗子数
F id 状态 x y 携旗角色 回位回合
EVENTS 事件数
E 类型 ...             （上一回合发生的事件，见下表）
END
```

- 坐标以左上角为 (0, 0)，x 向右增大，y 向下增大。阵营 k 的角色 id 为 3k、3k+1、3k+2。
- **角色**：阵亡时 x、y 为 -1；没带旗时"携带的旗"为 -1；活着时"重生回合"为 -1。
- **旗子**：状态为 `home`（在旗点）、`dropped`（在地上）、`carried`（被携带）、`cooldown`（交旗后离场）。后两种状态下 x、y 为 -1；没有携旗角色、没有回位回合时对应值为 -1。
- 重生回合或回位回合等于 t 时，重生或回位就发生在本回合开头。

| 事件 | 格式 |
|---|---|
| 旗子回位 | `E return 旗` |
| 重生 | `E respawn 角色 x y` |
| 命中 | `E attack 攻击者 目标` |
| 阵亡 | `E death 角色 x y 掉落的旗 击杀者人数 击杀者...`（没掉旗为 -1） |
| 拾旗 / 丢旗 | `E pickup 角色 旗`、`E drop 角色 旗` |
| 交旗 | `E capture 角色 阵营 旗` |

### 输出

一行：本回合编号，然后按 id 从小到大给自己的 3 个角色各写一个移动和一个动作：

```text
t 移动 动作 移动 动作 移动 动作 [# 注释;注释;注释]
```

- **移动**：`U` 上，`D` 下，`L` 左，`R` 右，`S` 原地不动。
- **动作**：`-` 什么都不做，`P` 拾旗，`X` 丢旗，一个数字表示攻击这个 id 的角色。
- **注释**（可选）：`#` 之后用分号分隔，依次对应 3 个角色，每条最多 20 个字，只显示在回放里，例如 `# 抢旗;护送;拦截`。
- 例：`37 R 4 U P S -` 表示第 37 回合，第一个角色右移并攻击 4 号，第二个角色上移并拾旗，第三个角色不动。
- 阵亡角色也要写，除非它本回合重生，否则会被忽略。回合编号不对、字段数量不对或出现未定义的字母，都算格式错误。

## 正式比赛

- 参赛的是其他模型写的程序，外加一个中等强度的基准。
- 覆盖从 2 方到全员的各种人数，每种人数权重相同。地图种子不公开；同一组程序会在同一张地图上轮换全部座位。
- 每局按得分排名，名次拆成两两胜负，用 Bradley–Terry 模型拟合实力值，基准为 0 分。
