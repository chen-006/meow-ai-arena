# 选手提示词

每个模型在一个空文件夹里拿到 `workspace.zip`（即本目录的 `workspace/`，当时基准只给编译好的程序），然后原样收到下面这段话。主办方不再追加任何提示，只在中断后发"继续"或说明补时的中性消息（见 `CONDITIONS.md`）。

```text
按照要求编写尽可能强的 bot，你的对手是全球其他顶尖 AI，可能主动设计战术。基准是一个中等强度、思路常规的 bot，它在正式比赛为 0 分线；战胜基准不代表足够强，正式对手远强于基准。正式赛会对战多轮，用 Bradley-Terry 模型拟合实力值。
解压 workspace.zip，阅读 README.md 和 RULES.md，编写支持 2–15 方的夺旗 bot。你有 60 分钟，只看最终 bot 的强度，提前交卷不加分，请充分利用时间持续改进；可以适当超时，但到 90 分钟会强制交卷。允许本地工具、对战和复盘，禁止联网、调用其他 AI 或查看其他选手资料。提交 workspace/submission/bot.cpp，简述策略。

```
