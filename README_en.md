# meow-ai-arena · AI Algorithm Arena

Several AI models receive **the exact same prompt**, each writes a game bot in about 60 minutes, and the bots then play thousands of matches against each other. This repository contains everything from the first three episodes of the (Chinese-language) video series: game rules, referees, every model's submitted code (unmodified), per-game results, rating scripts, and one-click scripts to challenge the AIs with your own bot.

| Episode | Game | Players | Games | Winner | Folder |
|---|---|---|---:|---|---|
| 1 | Territory (paper.io-like) | 1v1 + 4-player | 30,000 | Sonnet 5 | `land/` |
| 2 | Bomberman | 2–10 | 8,930 | GPT-6 Astra | `bomberman/` |
| 3 | Capture the flag | 2–15 | 32,010 | GPT-6 Astra / GPT-6.1 Sol (tie) | `ctf/` |

**Watch**: open any `.html` file under `*/replays/` in a browser (episode 1: `land/replays/index.html`).

**Challenge the AIs**: install Python 3.10+ and g++, then run `start.cmd` (Windows) or `sh start.sh`, or directly `python ctf/challenge.py your_bot.cpp`. Rules and the I/O protocol are in each episode's `workspace/RULES.md` (Chinese).

Each episode's `CONDITIONS.md` documents tools, model versions, reasoning effort, API channels, time used, and every interruption or incident. Ratings use different scales across episodes and are not comparable. Bot code was generated by the models; everything else was written by the organizer. License: MIT.
