# 头像出处（这些图片不适用 MIT）

这个目录里的头像是往期视频里用的角色形象，随渲染器原样附带，只为了能渲出和当时一样的画面。

- Opus、DeepSeek、Kimi、GLM、千问、Gemini、Grok 的形象来自 B 站博主 [ZipZipPipe](https://space.bilibili.com/4168597)。其中 DeepSeek 的鲸鱼娘是基于上善无形原创角色的二创（[原作来源](https://b23.tv/3dNz55h)）。
- 豆包用的是官方公开的形象。
- 其余由节目组制作；其中 Astra 的形象设计来自 B 站 小叶子XIYZ。

**这些图片不在本仓库的 MIT 许可范围内。** ZipZipPipe 不同意他的形象出现在带商业推广的视频里；要在别处使用，请先征得原作者同意。渲染器的代码仍然是 MIT。

从第 10 集起节目换了一套新形象，那一套在仓库顶层的 [`art/`](../../../../art/README.md)，是 MIT 的，可以放心用。想换头像：把同名的 png 放进这个目录即可。

# Avatar credits (these images are NOT under MIT)

The avatars here are the character designs used in the earlier videos. They ship with the renderer only so that it can reproduce the original look.

- Opus, DeepSeek, Kimi, GLM, Qwen, Gemini and Grok are by Bilibili creator [ZipZipPipe](https://space.bilibili.com/4168597). The DeepSeek whale girl is a derivative of an original character by 上善无形 ([source](https://b23.tv/3dNz55h)).
- Doubao uses its official public character.
- The rest were made by the show; Astra's design is by 小叶子XIYZ (Bilibili).

**These images are not covered by the repository's MIT license.** ZipZipPipe does not allow his designs in videos that carry sponsorships; ask the original authors before using them elsewhere. The renderer code itself is MIT.

From episode 10 on the show uses a new set of characters, published under MIT in the top-level [`art/`](../../../../art/README_en.md). To swap avatars, drop png files with the same names into this folder.
