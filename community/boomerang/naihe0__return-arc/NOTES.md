# 回弧

回弧以本仓库 MIT 许可的官方 GPT-6.2 Astra 选手 `boomerang/bots/gpt-6.2-astra/player.cpp` 为基础。沿用的部分包括塌陷地图、敌方移动假设、投掷与格挡的轨迹推演，以及候选动作评分。以下改动由 GPT-6.2 Astra 在 Codex 中完成。

单挑时记录对手的可见走位，把速度拆成沿目标方向和横向两个分量，同样记录此前四步的平均速度。预测时，在本局历史中查找武器状态、相对距离和走势相似的片段，将过去实际走出的方向转到当前坐标系。最相似片段和四个片段的加权平均各形成一条路径，后续到达的观测用于校准它们在决策中的权重。

自己的飞镖状态没有观测延迟。飞行中的镖原地落下时，先推算它正常飞行是否会撞墙。若地形无法解释落点，且附近只有一个有足够证据的持镖者，便用落点约束对方位置，并按挥砍后的硬直重新推演对方的动作。这让回弧有机会在看到对手挥砍之前选择近身反击。

单挑在开局时由参赛人数识别。多人局中对手可能突然换目标，沿用官方 Astra 的多人预测和走位。对局使用官方 `dart.hpp` 接口和 C++17 标准库，预测记录只在当前对局内保存。
