# Undertow（回流）

Undertow 从第 11 集官方 `template.cpp` 的选手接口起步，使用 C++17 和官方 `dart.hpp`。决策只使用本局的地图、参数和观察。单挑与四人局共用运动和碰撞推演，在站位、出手和生存收益上按存活对手数调整。

## 规则与对手研究

- 每步 0.05 秒。对手和其飞镖是四步前的快照，自己的状态是当前值。若对方在第 t 步发起动作，最早在 t+5 步才能观察到起手。近距离杀招可能在这以前生效。
- 按扫掠线段检测人和镖的相对运动。去程减速，折返点停留，回程追主人在本步移动后的位置。召回飞行可穿墙，地上镖可在拾取半径内直接拿回。
- 格挡比人镖碰撞更早结算，检查判定步开始时的镖位置。命中窗口通常只有一两步。冲刺中的前摇和收势也能被击中，移动末步要有落脚点。被踢期间只在滑行最后一步检查落坑。
- GPT-6.2 Astra 用多运动假设、对手瞄准学习和多步候选轨迹将武器优势转成连贯的走位。最值得借鉴的是主动迎镖、格挡后控制落点，以及把对手手中无镖的时间视为有限窗口。已发布的对局拆解也记录了空手遭踢和盲窗内被近距离投掷的失分。
- NeonVortex 用多阶段地图图搜索和主动格挡处理较长时间尺度，再用短程 `dart::Game` 校验接近战。它在持镖目标较远时更谨慎，会优先攻击冲刺落点、硬直和正在争夺地上武器的对手。近处精推依赖所选的对手反应模型，四人局还要承受第三方的交叉火力。
- 社区第二名 Sword 持镖作战，重视冲刺切入、格挡、近战后续和踢飞落点。在本轮独立 60 局单挑中，v15 和混战避险候选对它均为 21 胜、39 负，说明高海选综合分与克制纯手刀是两项不同的能力。
- Fable 5.2 把延迟快照重放到现在，维护不同的反应世界，走位有较强的方向持续性。Opus 5.5 的滚动推演重视主动拾镖。Carbon 和 Sol 也把格挡或冲刺接近战纳入候选。研究时以 `dart.hpp` 的默认参数和结算顺序校验笔记里的数值。

对照源文件位于本仓库的 [官方参赛程序](../../../boomerang/bots/) 和 [NeonVortex](../mattewsx__neon-vortex/)。

## 决策

1. **对齐观察。** 用八种移动假设补齐四步延迟，再继续往前推。其中七种分别拟合保持速度、近期平滑速度、停止、靠近、撤退或拾镖、向两侧横移。第八种由离线训练的小模型预测。用之后到达的实际快照更新各假设的预测误差，在对方持镖接近或争夺落镖等情况下参考各自的误差。碰到唯一合理的近身目标时，自己的实测推挤位移可即时修正中心位置。
2. **预测飞镖。** 外飞按官方步长、方向与剩余射程推算，回程按多条主人轨迹推算。对仍持镖的敌人，按其可看到的我方历史位置、速度及可能的瞄准方式构造盲区投掷。四人局还考虑第三方射线。若自己的镖突然落地，结合墙截断结果和碰撞位置估计此前发生的格挡或撞镖。
3. **比较候选。** 评估原地、走位、走后转向、冲刺、冲刺转近战、迎镖格挡、出镖和召回，每步只执行最优轨迹的第一条指令。用官方墙体和地形函数处理轨迹。候选将自己的飞镖与来镖放在同一时间线上，估计撞镖截断、先手击杀或打断后的风险，以及自己的武器何时重新可用。优先接受能在短时间内命中的投掷，按对手能否闪避、格挡或很快拿回镖调整出手机会。
4. **走位与生存。** 读取每一波塌陷地图，构造半格步行距离场和到永久陆地的代价。窄处、坑边和近战的踢飞落点由物理推演检查。单挑里格挡后提高控制对手落镖的收益。混战里额外计入第二近敌人、包夹角度和第三方射线。
5. **资源。** 使用官方协议入口和单线程。常规候选数受方向数、预测步数和有限分支约束。第 0 步预计算塌陷阶段的地图与路径数据。

## 本轮优化

- **拾镖延迟。** 对手持镖状态可能在最近四步内变化。对可见的落地镖，沿七条对手移动轨迹计算进入拾取半径的时间，累加各轨迹权重。从拾镖后的第一个可用输入步开始，按持有概率生成盲投和交叉火力。定点回归覆盖四步延迟内从距镖 800 毫米移动到 550 毫米并拾起，以及尚未拾起时的分支。
- **连续撞镖。** 对每条观测到的来镖轨迹记录自身飞镖最早相撞的时点。同一来源的预测互斥，另一来源的更早碰撞会减少后续截击和自身飞镖命中的概率。定点回归用官方 `dart::Game` 复现第 1 步撞落自己的镖、第 9 步第三把镖命中的情况。
- **多人存活。** 多于一名对手仍在场时，提高永久陆地、草丛、第二近敌和包夹角度的权重，增加对多条来镖的避险和对可闪避目标的出手门槛。残局只剩一个对手时恢复单挑距离与出手参数。

独立参照赛程采用种子 97579 和 13 名固定海选参照。只修拾镖分支为 157.19，只修撞镖分支为 157.10，两个修复合并为 170.26。精确近战复评、持镖激进贴身、提前预判冲刺和不同召回偏好也参加了对照。场景精推加激进贴身的组合没有在完整档复现收益，测得 171.2。

另一批 600 局强敌对照包含 NeonVortex、Astra、Fable 和 Sword。多人存活候选的四人局第一名由 30/360 增至 60/360，击杀由 238 增至 311。逐对得分率提升 12.04 个百分点，按地图和种子分块自助抽样的 95% 区间为 +7.04 至 +17.04 个百分点。对 NeonVortex 的单挑仍为 24 胜、1 平、35 负，四人局逐对比较为 89 胜、17 平、134 负。

RTX 4060 Laptop GPU 用 CUDA 训练了四步走位模型。训练样本 198,663 个，独立验证样本 145,402 个。平均位置误差由匀速基线的 591 毫米降至 461 毫米。训练后把权重写入单文件 C++，正式运行用 CPU 计算第八条移动假设。624 局新种子筛选中，仅多人存活时的综合实力值为 174.01，加入学习假设后为 193.84。按地图和种子配对，单挑与多人局的逐对积分增量区间仍包含零。

在 384 局强敌与额外地图对照中，学习版相对 v15 的单挑逐对得分率增量为 4.69 个百分点，四人局为 6.77 个百分点。相对只改多人存活的候选，单挑增量为 4.69 个百分点，四人局为 −2.34 个百分点。样本中对 NeonVortex 单挑 14 胜、3 平、31 负，四人局逐对比较 77 胜、15 平、100 负。

最终选用官方完整档分数最高的学习版。仅多人存活的候选在 97579 参照赛程和强敌额外地图上综合分更高，作为历史版本保留。把局分枚举再叠加到学习版时，624 局复测综合降至 176.22。

## 复现

Windows 与 g++ 环境下，从仓库根目录运行完整档。完整档覆盖六张海选地图，其中四张是原海选的保密地图。Python 3.13 可用 `PYTHON_CPU_COUNT=4` 将本机正式对局限为两局并行。

```powershell
python community/check.py community/boomerang/saner123321__undertow --full
```
