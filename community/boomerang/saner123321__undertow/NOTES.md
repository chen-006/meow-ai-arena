# Undertow（回流）

Undertow 从第 11 集官方 `template.cpp` 的选手接口起步，使用 C++17 和官方 `dart.hpp`。决策只使用本局的地图、参数和观察。单挑与四人局共用运动和碰撞推演，在站位、出手和生存收益上按存活对手数调整。

## 规则与对手研究

- 每步 0.05 秒。对手和其飞镖是四步前的快照，自己的状态是当前值。若对方在第 t 步发起动作，最早在 t+5 步才能观察到起手。近距离杀招可能在这以前生效。
- 按扫掠线段检测人和镖的相对运动。去程减速，折返点停留，回程追主人在本步移动后的位置。召回飞行可穿墙，地上镖可在拾取半径内直接拿回。
- 格挡比人镖碰撞更早结算，检查判定步开始时的镖位置。命中窗口通常只有一两步。冲刺中的前摇和收势也能被击中，移动末步要有落脚点。被踢期间只在滑行最后一步检查落坑。
- GPT-6.2 Astra 用多运动假设、对手瞄准学习和多步候选轨迹将武器优势转成连贯的走位。最值得借鉴的是主动迎镖、格挡后控制落点，以及把对手手中无镖的时间视为有限窗口。已发布的对局拆解也记录了空手遭踢和盲窗内被近距离投掷的失分。
- NeonVortex 用多阶段地图图搜索和主动格挡处理较长时间尺度，再用短程 `dart::Game` 校验接近战。它在持镖目标较远时更谨慎，会优先攻击冲刺落点、硬直和正在争夺地上武器的对手。近处精推依赖所选的对手反应模型，四人局还要承受第三方的交叉火力。
- Fable 5.2 把延迟快照重放到现在，维护不同的反应世界，走位有较强的方向持续性。Opus 5.5 的滚动推演重视主动拾镖。Carbon 和 Sol 也把格挡或冲刺接近战纳入候选。研究时以 `dart.hpp` 的默认参数和结算顺序校验笔记里的数值。

对照源文件位于本仓库的 [官方参赛程序](../../../boomerang/bots/) 和 [NeonVortex](../mattewsx__neon-vortex/)。

## 决策

1. **对齐观察。** 用七种移动假设补齐四步延迟，再继续往前推。分别拟合保持速度、近期平滑速度、停止、靠近、撤退或拾镖、向两侧横移。用之后到达的实际快照更新预测误差，在对方持镖接近或争夺落镖等情况下参考各自的误差。碰到唯一合理的近身目标时，自己的实测推挤位移可即时修正中心位置。
2. **预测飞镖。** 外飞按官方步长、方向与剩余射程推算，回程按多条主人轨迹推算。对仍持镖的敌人，按其可看到的我方历史位置、速度及可能的瞄准方式构造盲区投掷。四人局还考虑第三方射线。若自己的镖突然落地，结合墙截断结果和碰撞位置估计此前发生的格挡或撞镖。
3. **比较候选。** 评估原地、走位、走后转向、冲刺、冲刺转近战、迎镖格挡、出镖和召回，每步只执行最优轨迹的第一条指令。用官方墙体和地形函数处理轨迹。候选将自己的飞镖与来镖放在同一时间线上，估计撞镖截断、先手击杀或打断后的风险，以及自己的武器何时重新可用。优先接受能在短时间内命中的投掷，按对手能否闪避、格挡或很快拿回镖调整出手机会。
4. **走位与生存。** 读取每一波塌陷地图，构造半格步行距离场和到永久陆地的代价。窄处、坑边和近战的踢飞落点由物理推演检查。单挑里格挡后提高控制对手落镖的收益。混战里额外计入第二近敌人、包夹角度和第三方射线。
5. **资源。** 使用官方协议入口和单线程。常规候选数受方向数、预测步数和有限分支约束。第 0 步预计算塌陷阶段的地图与路径数据。

- 一批 468 局对照里，v03 的 139.07 在取消回镖时钟对焦点站位、近战风险和投掷门槛的影响后降到 111.79。仅移除交叉火力射线则得到 144.22，该增量的贡献存在不确定性。

- 两张自制地图分别放入狭窄通道、错位坑岛与石墙。对每个版本打 160 局，覆盖换座和四人轮座。增加跨坑连边及撤离截止时间的 v09 在这批赛程中综合估计 130.69，v07 为 149.22，v10 为 149.47。
- 古塔种子 19607 的一场早期回放中，v01 在第 51 步起冲刺，第 56 步 NeonVortex 按落点出镖，第 60 步在我方刚恢复自由后的短窗口命中。另有天桥回放出现撞镖后对手先捡回自己的镖并迅速再投。这两类失分促成曝光冲刺惩罚和使用己方落镖反推出手状态。
- 168 局 v14 调试版回放共记录 115 次出局，其中 78 次中镖、18 次被砍、19 次落坑。498 次出镖中有 95 次至少命中一次，另有 62 次撞镖和 15 次被格挡。自由状态下大幅输入移动但实际位移小于 60 毫米的步共 1131 个，可能涉及贴墙、推挤或刹车。以裁判位置为基准，记录到的焦点对手当前预测误差中位数为 0.44 米（21282 个样本），四步后为 1.12 米（20742 个样本）。

## 投稿版本和复现

锁定 v15。完整档覆盖六张海选地图，其中四张是原海选的保密地图。v15 在选型完整档中取得综合 177.3，海选参照第 2/14，一对一 229.7，四人局 124.8。10 步超时，0 次非法输出，0 局崩溃、失去响应或被结束。第 0 步 CPU 峰值 73.77 毫秒，之后单步峰值 16.86 毫秒。

另外使用独立种子从 30913 开始，v15 与 NeonVortex 单挑 96 局，36 胜、1 平、59 负。在 v15、NeonVortex、Astra、Fable 同桌的 192 局中，按局分与 NeonVortex 逐对比较为 52 胜、19 平、121 负。近距离盲区和混战生存仍是主要短板。NeonVortex 在社区榜公开值为 290，在本机完整档基线测得 309.5。社区实际名次取决于 GitHub 的评测结果。
