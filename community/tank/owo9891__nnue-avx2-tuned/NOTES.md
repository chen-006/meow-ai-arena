# NNUE Vanguard·AVX2 调优版 — 思路说明

## 来源

基于社区投稿 `community/tank/lite0812__nnue-vanguard/bot.cpp`（官方 NNUE Vanguard，MIT 许可）修改。
原始作者：lite0812；本次改动由 AI 多模型协作完成，署名见 `meta.json`。

## 改动

1. **推理加速（AVX2/SSE2）**：给 NNUE 推理的累加器、L1/dense、policy/value head 增加 SSE2 与 AVX2 内核；运行时用 `__builtin_cpu_supports` 检测 CPU：有 AVX2 用 AVX2，无 AVX2 回退 SSE2，再回退标量。所有内核与标量路径做过逐位一致性自测（mismatches = 0）。
2. **搜索参数调优**：先验温度 0.9、局部搜索深度上限 14、PUCT 系数 1.0（其余保持原版）；按正式 CPU 预算截止。
3. **预算**：常规回合 47 CPU 毫秒、首回合 1800 毫秒（低于官方 50/2000 上限，留出调试与解码余量）。
4. **权重压缩**：神经网络权重用无损编码（CM+rANS）打包，使单文件满足社区 256 KiB 上限（本文件 ≤262,144 字节）；解码结果与训练导出权重逐字节一致（5 个 -O 级别复检）。

## v2：全网络 QAT 重训（3000 局教师自对弈）

- 数据：3000 局 **8192-sims 教师自对弈** → 1,068,120 条逐 decide 样本；
- 训练：全网络量化感知训练（embedding 3504×60 int8 + dense 96×60 int8 + heads），按局切分、双侧零和正则；固定验证集 policy CE −2.0%、value MSE −0.7%；
- 实测（对 v1 镜像 A/B）：1000 图/2000 局，53.70%（95% CI [50.85, 55.12]）；外部非同族 bot 泛化无退化。

## v3：trunk 训练修复

- 诊断：v2 实际只有 heads（约 1.2% 参数）被有效更新，embedding/dense 权重变化 ≤1 LSB，trunk 几乎未训练；
- 修复：embedding/dense 使用 30× 学习率、20 epochs（QAT 不变，导出仍 int8/int16）；trunk 实际变化 embedding 63.4%（平均 2.5 LSB）、dense 55.0%；固定验证集 CE 1.23523→1.20911、MSE 0.72258→0.69409；
- 实测（对 v2 镜像 A/B）：1000 图/2000 局 69.47%（95% CI [67.15, 70.95]）；官方参照池 1280 局 1274-0-6。

## v4c：地图分层数据 + 抗漂移小步迭代（本版核心）

- **地图分类数据**：按量化地图分类标准（地形构成/连通性/割点/中央墙/弹道视线/星区可达/竞速等 7 标签）构建分层种子库，生成 **3849 局 v3@8192 教师自对弈**（1,475,682 样本，覆盖 WATER/MAZE/STAR_HARD/RUSH 等类型）+ **160 局对手混合数据**（vs Opus/sparring）。
- **抗漂移训练**：从 v3 权重初始化，旧+新数据混合（42:58）、trunk 学习率 10×、4 epochs，并以旧分布验证集设护栏（防遗忘）；trunk 实际变化 36%。
- **实测**：
  - 官方参照池全量 1280 局：**1278-0-2、fixed-final 实力值 1112.6**（v3 为 1274-0-6 / 1052.7；失手 6→2，仅 Astra/SolUF 各 1 负）；
  - 镜像 A/B（vs v3 提交版）：**1000 图/2000 局 54.20%**（detail 56.67%，95% CI [54.6, 58.8]）；
  - 外部非同族 bot 泛化（gen2，200 图/400 局）：**Overmatch batch +2.75pp / detail +4.75pp（CI 排除 0）**、neural-search batch +1.12pp / detail +1.75pp；无系统性退化；
  - v3 的 4 个已知失手局面（Opus×2/sparring×2）在 held-out 回归中 **4/4 全胜**。

## 合规说明

- 只包含官方 `tank.hpp`、C++ 标准库与**编译器自带的系统头**（`<immintrin.h>` 等）。选手包 README 明确允许这类系统头；不依赖任何外部文件、库或运行时数据。
- 不读写文件、不联网、不启动其它进程；单线程；不保存跨对局信息（权重解码在 `init` 中、只用于本进程）。
- 无 AVX2 的评测机也能运行（自动回退 SSE2/标量）。
