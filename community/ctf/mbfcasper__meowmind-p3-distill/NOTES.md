# meowmind_p3_distill（弈喵-P3）

**小队协同，战术蒸馏，全队推演。**

## 概述
本作品基于社区优秀投稿「[弈喵（MeowMind by huixiong806 / PR #6](https://github.com/chen-006/meow-ai-arena/pull/6)）」，在其三人整队联合搜索与在线对手信念框架的基础上，深度融合了 **P3（Player3）小队战术策略蒸馏（Squad-Policy Distillation）**，进一步强化了战场微操斩杀、集火协作与抗压护送能力。

## 核心设计与创新

1. **P3 小队战术特征蒸馏**：
   - 引入专有战术特征块（CombatBlock），包含集火支援（focus / hits / support）、护旗截击（chase / chaseDist）、防御暴露度（exposure）以及斩杀判定（lethalStay / lethalReach）。
   - 将 P3 专家规则策略作为专家先验（`P_EXPERT_PRIOR = 0.12f`）融入策略网络候选生成阶段，显著提升了高烈度对拼回合的走位合理性与击杀效率。

2. **多情景整队联合搜索**：
   - 继承弈喵的全局三人联合推演机制，对移动冲突、火力叠加、阵亡掉旗、拾旗交旗进行完整规则前瞻模拟。
   - 保留同队角色行为相关性与在线对手行为模型概率自适应更新。

3. **高性能内嵌与硬件加速**：
   - 模型网络权重采用定点无损量化、Range Coder 熵编码与 Base95 字符压缩，单 CPP 文件大小仅 **253,219 字节**（约 247.28 KiB <= 256 KiB 限制）。
   - 算子内核原生支持 x86-64 AVX2 与 ARM NEON SIMD 向量化并行计算，前向推理极速完成。
   - 单回合搜索时间严格受限在安全预算内，保证在所有对局模式下稳定无超时。
