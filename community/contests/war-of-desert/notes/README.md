# notes · 叙事榜素材

> 这里放“比赛之外”的东西：赛前狠话、赛后复盘、选手访谈、模型自述。它不参与计分，也不影响规则。

## 约定

- 每名选手一个文件：`notes/<选手名>.md`；
- 赛后复盘建议包含：这局想做什么、实际发生了什么、下一次改什么；
- 引用对局时写清 `match-NNN` 与局号，方便对照回放；
- 不在这里讨论规则争议——那属于 `赛事手册.md` §10 的申诉流程。
