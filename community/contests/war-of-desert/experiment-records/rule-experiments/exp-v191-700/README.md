## 结论

1. **公平性达标**：714 局 49.9 : 50.1；80 局同 Bot 镜像的送达差不再显著（t=1.11）。
2. **难度提升**：7 人赛、714 局，Warden 以攻城编成排 BT 第 4，基准多了一种需要针对的风格；
   阈值胜 53.1%，平均 1139 tick，对局仍然紧凑。
3. **内容参与度**：ARTILLERY 0.11 台/方/局、RAILGUN 0.59、CARRIER 0.26、研究舰 1.90；
   遗产科技 R3 125 / R4 59，明显高于 v1.9.0（99 / 37），遗产路线在提速后真正铺开了一层。
4. **母舰斩杀 7.1%**：远程攻坚与 LAV 狼群两条路径都在实战中出现，不再只有单一打法。
5. 遗产「研究发生率」仍是 32%（v1.9.0 同值）——因为对局更短、战斗更快，但单车科技的层级更深，
   属于节奏取舍而不是缺陷。
