| 单位 | v1.8.0 | v1.8.1 |
|---|---|---|
| RAILGUN | 320 CU / 60 RU | **240 CU / 40 RU** |
| ARTILLERY | 950 CU / 250 RU | **650 CU / 180 RU** |

- 参考 Bot 保留拆舰编成：Vanguard RAILGUN + Siege、Bulwark ARTILLERY + Siege、Nomad CARRIER。

## 结论

1. 降价把远程兵产量抬上来了：RAILGUN 0.33 → 0.43 台/方/局（+30%），
   ARTILLERY 0.04 → 0.075（+81%）。
2. 母舰斩杀率 2.0% → 2.5%（10 → 13 局），方向对了，但量级仍然很小；
   母舰终局 HP 99.7%，说明绝大多数对局根本没碰到母舰。
3. 平局 22.4% → 21.2%，阈值胜 25.3% → 26.3%，基本回到 v1.8.0 的水平；
   座位 48.7 : 51.2，仍在噪声范围内。
4. 判断：单靠降价不足以让拆舰成为主路线。RAILGUN 一局约 0.43 台，要打掉 1800 HP
   还需要持续输出 600+ tick；ARTILLERY 即便降到 650 CU，一局也只有 0.075 台。

## 建议的下一步

- **A. 继续加大力度**：RAILGUN 200/30、ARTILLERY 500/150，或同时给对母舰伤害 ×1.5。
- **B. 直接降母舰 HP**：1800 → 1400，让现有输出量级能在 1500 tick 内完成击杀。
- **C. 接受当前结果**：v1.8.1 的 21.2% 平局、2.5% 斩杀已接近 v1.8.0，拆舰作为支线存在即可。
- **D. 回退到 v1.8.0**：如果不需要拆舰路线，回退远程兵降价与编成改动。
