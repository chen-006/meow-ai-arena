## 结论

1. **座位公平已改善**：决胜局 seat0/seat1 = 52.2/47.8，接近 50/50；v1.5 的 67/33 座位偏置已消除。
2. **研究舰/遗产科技确实进入实战**：100% 对局造出研究舰，93% 出现研究，R1/R2 基本普及，R3 常见，R4 较少。
3. **主要问题是平局率 46.3%**：VS 中位数 100、均值 130，双方常常各拿 100 遗产分后都不打架，KD 和母舰 HP 也相同，直接判平。
4. **单纯把阈值降到 250 不能解决平局**：平局多发生在 100:100，双方都没到 200；需要增加战斗收益或增加终局 tie-break。
5. 当前阈值 300 下，阈值胜只有 12.1%，时间到占 84.7%；若目标是减少时间到，可把阈值降到 250，但平局仍需单独处理。

## 建议的下一轮校准

- 在判定链最后增加 tie-break：**遗产科技等级 → 旗控制时长 → 唯一送达遗产件数**，再判平。
- 或提高击杀收益（如 `min(造价/1.5, 200)`），让 100 遗产 + 3 个 LAV 击杀即可到 300。
- 若保留 300 阈值，建议同时观察“阈值胜占比”和“平局率”，不要只调阈值。
