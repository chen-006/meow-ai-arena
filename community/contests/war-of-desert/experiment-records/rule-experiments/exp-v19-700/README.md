## 结论

1. **公平性**：决胜座位 51.8 : 48.2，仍在 50 ± 2pt 内；换边赛制下没有可见座位偏置。
2. **难度与内容**：7 人赛、21 组对阵、714 局；ARTILLERY 0.08 → 0.10 台/方/局、RAILGUN 0.52 → 0.59，母舰斩杀 4.7% → 6.6%，远程路线比 v1.8.3 更常出现。
3. **遗产科技仍然偏弱**：虽然 R1–R4 研究时间缩短了 25%，对局也更短更激烈，研究发生率反而 37% → 32%，R1 完成数按每局折算略降。需要在 v1.9.1 里直接提高遗产补给。
