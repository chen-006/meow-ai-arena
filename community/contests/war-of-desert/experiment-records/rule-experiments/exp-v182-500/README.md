# exp-v182-500 · v1.8.2 500 局实验（对母舰伤害 ×1.5）

> 规则 v1.8.2（ruleset v15）｜ 1500 tick ｜ 6 名参考 Bot ｜ 510 局
> 相对 v1.8.1：只给 RAILGUN / ARTILLERY 对母舰伤害 ×1.5

## 本轮改动

- 新增 `MothershipSiegeMul = 1.5`：仅在 v15、目标为 MOTHERSHIP、来源为 RAILGUN/ARTILLERY 时生效，
  在 RPS 克制倍率之后结算（`hitUnit`）。
- 写入 v15 规则指纹（`|siegeMul:1.5`）。
- 造价、击杀分、人口 36、拆舰编成全部保持 v1.8.1，便于单变量对比。

| 阈值胜 | 134（26.3%） | 134（26.3%） |

| 决胜座位 seat0 : seat1 | 194 : 204 | 194 : 204 |
| 母舰被摧毁 | 13（2.5%） | 13（2.5%） |

**两轮结果几乎完全一致**：510 局里只有 11 局的 `turn`/`totals` 发生变化，
胜负、判定原因、座位分布全部相同。倍率确实生效了（指纹已变），但几乎没有机会打到母舰。

## 为什么没效果

| 观测 | 数值 |
|---|---:|
| 至少一方远程兵进入敌母舰 250 px 内的对局 | **28 / 510（5.5%）** |
| 母舰掉过血的对局 | 25 / 510（4.9%） |
| 远程兵单位曾进入 ARTILLERY 射程（≤336 px） | 33 / 210（15.7%） |
| 远程兵单位曾进入 RAILGUN 射程（≤228 px） | 20 / 210（9.5%） |
| RAILGUN/ARTILLERY 到敌母舰最近距离中位 | **994 px** |
| LAV 到敌母舰最近距离中位 | 813 px（≤228 px 仅 2.9%） |

单台 RAILGUN 的轨迹（seed 20261113）：t=800 从基地出发，一路推进到 t≈1160 的 (651,493)，
距离敌母舰仍有 1059 px，然后**原地停到终局**（t=1480 位置不变，HP 满）。

结论：**瓶颈不是伤害，也不是造价，而是「走不到母舰」。** 地面单位在中途被地形/坡道卡住，
母舰终局 HP 仍有 99.7%；在这种情况下把伤害 ×1.5 自然没有任何效果。

## 结论

1. 伤害倍率生效但无效：远程兵在 84% 的对局里从未进入自己的射程，母舰只掉过 4.9% 的对局的血。
2. LAV 同样到不了母舰（中位 813 px），说明这是**全兵种的地面接近问题**，不是拆舰兵特有。
3. 继续加伤害/降价是浪费变量；下一轮必须解决「接近母舰」的路径与地形问题。

## 建议的下一步

- **A. 工程化接近路线**：查 `botkit` 流场与引擎 `StepAllowed` 的不一致（bot 只按山格判定，
  引擎还判坡度），让远程兵能沿可达坡道绕行；必要时给 RAILGUN/ARTILLERY 增加「可涉水/跨浅沟」。
- **B. 地图侧**：复核母舰/基地外圈的可达性，保证每张图至少有一条宽通道能让所有地面单位走到敌方基地。
- **C. 换胜利条件**：承认拆舰在当前地图上不可行，把胜负重心放回 VS/旗控制。
- **D. 接受 v1.8.0/v1.8.1 的结果**，不再追求拆舰路线。
