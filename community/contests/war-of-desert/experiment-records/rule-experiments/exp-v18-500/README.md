> 规则指纹：`90c3c937` ｜ 引擎：native ｜ 验证：开

## 本轮改动（相对 v1.7.2）

- 人口上限 24 → **36**（仅 v15，`PopMaxV15`；v1.4 保持 24），写进 `hello.economy.popMax` 与 v15 指纹。
- Vanguard / Nomad / Bulwark 打开 `Push`：六个参考 Bot 全部会主动压向敌方 VP，
  不再各守半场。
- tie-break 链保持 v1.7.2：VS → KD → 母舰 HP → 旗控制（>5%）→ 平。

依据：v1.7.2 里敌我最近战斗单位距离中位 558 px（半张地图），≤80 px 只占 6.1% 的帧，
峰值 11.3 台 → 终局 10.9 台、母舰终局 HP 99.8%，战斗几乎没有发生。

## 结论

1. **平局减半再减半**：48.0% → 21.0%；阈值胜 18.4% → 27.9%，时间到 79.2% → 69.9%。
2. **座位公平同时改善**：决胜座位 201:197（50.5/49.5），比 v1.7.2 更均衡。
3. 战斗确实发生了：敌我最近距离中位 558 → 399 px，≤80 px 帧占比 6.1% → 10.1%，
   歼敌领域均值 5.6 → 10.0，场均生产 15.0 → 17.9 台。
4. **母舰斩杀率仍然只有 2.0%**：RAILGUN 每方每局仅 0.22 台，ARTILLERY / CARRIER 从未建造；
   远程拆舰这条线基本不存在。
5. 遗产与科技被战斗挤占：送达 3.42 → 2.78，科技 6.3 → 5.65，研究发生率 93% → 82%，
   但仍在正常区间，没有出现「打起来就没人管遗产」的断层。

## 可选下一步

- **A. 接受 v1.8.0**：21% 平局、50.5/49.5 座位、阈值胜 28%，可作为实验规则定稿。
- **B. 继续压平局**：给参考 Bot 建造表加入 ARTILLERY / CARRIER（远程拆舰），
  或提高击杀胜利分，把剩余 107 局对称僵局再压一半。
- **C. 提高斩杀率**：调整远程单位性价比（RAILGUN 造价/射程/伤害），让「拆母舰」成为可行胜利路线。
